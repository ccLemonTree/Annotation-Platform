# 通用目标属性分析

大模型预标注支持先手工标注一张正确范例，再将范例图片和属性一起传入。检测项目也支持同类能力，详见[预标注正确范例](预标注正确范例.md)。

在项目管理创建“大模型描述 / 目标属性分析”项目，或打开既有描述、向量项目，点击“目标属性分析”。功能适用于任意设备、场景及模型支持的目标，不固定低位交通或车辆。

未配置属性的项目从空白开始，不自动载入车辆属性。已有项目会显示其已保存配置，与模板下拉框当前是否选中无关。“新建空白配置”只清空当前草稿的检测标签和属性，可从头定义动物等任意对象；点击“保存属性配置”后才替换项目配置，历史标注仍保留原配置快照。检测标签或属性为空时不能保存配置和模板。

准备区的检测标签与上方草稿同步显示；有未保存修改时标记“待保存”并禁止启动属性分析，保存后才可按新配置创建批次。历史批次继续使用创建时的配置快照。

后台处理队列按用户启动的流程展示，自动属性子批次归入对应原图检测流程。每行分别显示检测原图和属性目标的完成、等待、处理、失败数，以及模型、创建时间和等待原因；进入明细可看图片名称和具体错误。属性分析仍按队列依次执行，等待不等于模型失败。

属性结果选中某个属性后，默认显示“已分析（含无法判断）”，只展示该项属性；“全部（含尚未分析）”和“尚未分析此属性”可用于查看待处理目标。属性值为精确匹配，配置过可选值时提供输入提示。筛选、分页和导出使用同一范围，无法判断与尚未分析分开统计。

## 使用

1. 配置检测目标标签，输入后回车，可添加多个，例如 `car`、`bus`、`truck`。所选检测模型必须支持这些标签；只裁剪所选标签的检测结果。同批目标共用一套属性，需要不同属性时分别创建分析批次。准备区的“修改目标标签”可跳回配置。
2. 可载入人员、车辆、通用物品三种内置模板，或把当前配置“保存为模板”以便跨项目复用。自定义模板保存在服务端，仅同租户管理员可读取、保存和删除；删除模板不影响已应用的项目配置和历史标注。物品模板的 `object` 需改为检测模型支持的具体物品标签。
3. 编辑需要分析的属性：名称、判断说明和可选值。可增删属性；最多30项，没有可选值表示自由文本。车辆模板提供车牌、车牌类型、车牌颜色、车辆类型、车身颜色、车辆品牌、车身朝向。载入模板只修改当前草稿，需要另行保存属性配置。
4. 保存属性配置。进入“按任意场景选择设备并拉图”，选择设备并创建绑定此项目的定时抓图计划；也可上传或复用已有图片。设备场景多选默认任一匹配，可切换全部匹配形成交集，不限定特定场景。切换场景条件会清空已选设备。
5. 回到目标属性分析，处理方式选择“检测切图并预标注属性”，选检测模型、OpenAI视觉对话属性模型、置信度和外扩比例，再勾选原图并启动。每批最多5000张原图，超过时自动分批。检测后自动为每张目标切图创建属性分析项；在检测项中点击“查看逐目标属性批次”查看进度、失败原因、取消或重试。
6. 处理完成后刷新属性结果，点击“修正属性 / 审核”。每个属性可以填写值，或勾选“无法判断”并填写原因。保存形成新版本并回到待审核；人工核对后通过或驳回。
7. 选择属性，按精确值或已确认 / 无法判断 / 尚未分析筛选，可同时筛选审核状态。导出当前筛选范围所有分页的结果，默认只含审核通过；可明确包含待审核，已驳回不导出。

定时抓图持续把图片加入项目；检测与属性分析由用户从项目中主动启动，不自动消耗模型处理全部历史图。重复检测复用同项目切图，有标注时保留原结果。需要更新属性时选择切图，使用“大模型预标注属性”建立新的批次。

## 结果与保护

属性结果为 `{value: 字符串或null, reason: 原因}`。模糊、遮挡、不可见、模型漏返回的属性保存为null；枚举外结果也转为null并说明原因。非法JSON、重复键或截断输出标为失败，不写入标注。无法判断不是否定，也不能用空字符串代替。

属性分析模型支持已启用的OpenAI视觉对话或 `jev_decide` 协议。FastVLM LPR的普通描述接口不能作为通用结构化属性模型。通用功能不更改模型服务配置；模型不支持目标时须调整模型或目标配置。

## JEV /v1/decide 属性选择

在“模型管理”添加模型：用途选“图像描述”，协议选 `jev_decide · JEV属性选择`，URL 填 `http://36.138.253.82:10998/v1`，ENDPOINT 填 `/decide`，模型 ID 留空即可。连接测试只读取 `/v1/decide/info`，不发送图片；模型管理的通用描述试运行不用于此协议。

在项目“目标属性分析”设置目标及属性。例如人员 `person`，帽子可选值为“鸭舌帽、头盔、没戴帽子”，衣服为“反光衣、防尘服、厨师服”。保存配置后，在“检测切图并预标注属性”选择检测模型和 JEV 属性模型；已有单目标图可直接选择“大模型预标注属性”。每项属性都必须填写可选值，不支持自由文本或正确范例。可按业务加入“其他”“无法判断”等候选，避免选项未覆盖实际情况时被迫归类。

每个目标内的属性依次调用 `kind=choice`，请求包含目标上下文 `state`、属性名称与判断说明 `question`、可选值 `options` 和 `thinking=off`。图片沿用现有缩放及 JPEG 编码，单属性超时沿用模型配置；不同目标仍受平台现有项目并发数限制，不额外增加属性并发。

返回选项须与请求一一对应（允许重新排序）；概率必须为0—1的有限数字，缺失、重复、未知选项或错误概率会使本图分析失败，不保存部分属性。最高概率项作为待审核建议；最高概率并列或命中“无法判断”等未知候选时，属性值保存为 null 并说明原因。所有候选原始概率保存在属性的 `probabilities` 字典中，不把概率当作已验证正确率或自动审核依据。

属性结果列表及人工工作台均可展开“查看模型原始候选概率”。人工修改属性值、原因或改为无法判断后，仍保留原始概率；概率为后端保护的只读证据，不能通过人工标注接口伪造或修改。修正产生新待审版本，继续沿用原有审核操作。历史 OpenAI 属性没有概率时不显示此区域。

属性导出的 `annotations.jsonl` 和 `manifest.json` 保留完整概率字典；`attributes.csv` 在末尾追加 `probabilities` 列，内容为选项到概率的 JSON，无概率时留空。原始概率与人工最终属性值分别保留。审核范围、筛选和所有分页沿用原规则；无需数据库迁移，不改写历史标注或已有模型配置。

批次固定属性与模型配置。取消、人工修改、审核、图片变化、配置变化或创建人失去权限都会阻止迟到结果写回。修改配置不重写旧标注：旧标注保留原属性定义，人工修正和导出沿用其快照。

管理员配置、拉图、启动处理和导出；普通用户沿用已分配项目的人工标注与审核权限。原图及检测框保留在切图来源中，项目私有切图不会进入共享图片库。自定义模板功能使用迁移036新增独立表，不改写既有项目和标注。

准备区“选择当前筛选全部图片”包含所有分页，遵循当前图片来源和项目标注范围，并排除已选择的正确范例。跨页保留勾选，切换范围会清空选择，可“清空选择”后重新勾选。超过5000张自动拆成多个后台批次；中途提交失败时，已成功批次保留，剩余图片仍选中，重试只提交剩余部分。

## 后台处理并发

`PROJECT_WORK_CONCURRENCY` 控制项目图片处理的并发数，默认4，允许1至128，HTTP连接池随并发数设置；每次请求使用新连接，避免NodePort连接复用将批次固定到少数模型副本。每项属性分析仍一次请求返回全部属性。该上限是平台配置范围，实际值须按模型副本数、单副本容量和负载测试选择。保持单个后端服务进程，使用数据库行锁领取任务、版本与快照校验隔离迟到结果；异常恢复等待同组请求结束，不会把同组仍在处理的项标记失败。修改并发配置后重启后端生效。

## 人工标注工作台筛选

目标属性使用紧凑行展示，候选旁的概率为模型原始值；有概率时直接显示前三个候选按钮，可一键修正，其他选项仍可从搜索下拉框选择。属性判断说明与可选修正原因默认收起；选择“无法判断”后，原因输入框始终显示且必须填写。点击无法判断类候选也按未知状态保存，不把未知当作具体类别。完整候选概率仍可展开查看，人工修改不改变原始概率。

审核操作固定在属性滚动区下方，核对最后一个属性时仍能看到原图及按钮。点击“保存并通过，下一张”或在非输入区域按 `R`，依次保存修改、人工通过审核、读取当前图片集/标签/审核筛选下的下一张。未修改的已保存标注不创建重复版本；已通过的标注不重复提交审核。保存或审核失败停留当前图片；若仅下一张读取失败，已经成功的保存和审核保留，再次点击可继续取下一张。最后一张通过后停留并提示，不跳到其他筛选范围。单独保存、通过、驳回仍保留，`Ctrl+S` 保存，`Shift+R` 驳回。

图片分类、描述及目标属性工作台与目标检测工作台一样，支持按图片集、最新已保存的图片分类标签及审核状态组合筛选。属性标注工作台另有“属性”筛选，可选择项目属性或当前标注保留的历史属性，按精确值以及已分析、已确认值、无法判断、尚未分析状态筛选；选择属性后默认查看已分析结果。值可从枚举建议中选择，也可输入文本后按回车或“筛选”应用，不会在输入过程中反复切图。未知和缺失状态不同时使用具体值。

上一张、下一张、序号跳转及“保存并通过，下一张”均沿用全部筛选和项目标注范围，数量、序号也按筛选结果计算。查询只读取最新已保存的属性，未保存时禁止修改筛选。改标后不再匹配的图片会显示提示，仍可从当前锚点进入筛选内的相邻图片；清除筛选会一并清除属性条件。无结果或查询失败时保留当前图片及原条件。列表、全选和相邻图片 API 使用相同属性查询，前端要求后端返回属性筛选能力标识，避免旧服务忽略参数而展示未筛选队列。

未保存修改时不可切换筛选；无匹配或读取失败时保留当前图片与条件。保存或审核后重新定位当前图片，若已不符合筛选会提示，并可清除筛选或继续切换到匹配图片。图片与属性区独立滚动。

## 导出

ZIP包含目标切图、`annotations.jsonl`、`attributes.csv`和`manifest.json`。JSONL为每目标一行，包含属性结果、配置快照、标注版本、审核状态、内容SHA256和原图/检测框来源。CSV每属性一行，包含目标ID、图片路径、目标标签、属性标识/名称、值、原因和来源，未知值为空；表格公式前缀进行转义，JSONL保留原文本。manifest记录本次筛选条件和审核范围。

同一原图的切图须保留在同一训练/验证划分，本包不自动划分。现有通用标注包也保留结构化属性；属性专用导出入口便于按筛选范围取数。

模型可能漏检或误判。当前实现检查数据格式、可选值和无法判断规则，所有自动属性均待人工审核；这不代表已验证某模型的车牌、品牌或人物属性准确率。
