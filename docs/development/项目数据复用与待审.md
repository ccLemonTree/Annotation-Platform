# 项目数据、复用与待审

## 项目流程与模型入口调整（2026-11-04）

- 新建项目不自动打开上传。卡片提供“管理项目图片”和“删除项目图片”；后者复用现有全量删除确认，显示数量和项目范围，取消不执行删除。单图、勾选和筛选范围删除仍在项目图片页。
- 项目上传、旧上传接口、未显式选择图片集的SmartEye项目采集，默认使用项目名称作为图片集名。显式指定的图片集和既有名称不迁移。
- 图片集、复用选择器和项目图片可按来源平台、设备名查看。平台读取当前范围已有来源；设备名支持包含匹配。多来源图片要求平台和设备匹配同一来源；列表、全选和项目删除范围使用相同条件。未记录平台显示“本地上传 / 未记录平台”，分组为逻辑查询，不移动原文件。
- 主菜单“数据资产”改为“项目与数据”，“模型效果预览”改为“模型测试与评估”。快速测试和数据集评估在同页切换；旧 `/validation` 链接保留参数转入评估视图，不再占用独立菜单。
- 当前配置版本已判定离线的模型在标注、预标注、AI审核、向量检索和处理选择器中禁用；默认值跳过离线模型。创建后台标注批次时同样拒绝当前离线模型。修改配置后旧连接检查失效，重新连接测试可恢复可用状态；不会因该改动批量停止已经运行的任务。


## 2026-11-04 项目入口与共享规则

以下规则替代下文旧版本关于“全部原图库可直接共享”的描述。

- 项目、模型分组和模型版本使用卡片展示，保留分页、下载、版本详情及已有操作。项目卡片内可上传、定时采集、复用已审核数据、启动检测预标注和AI审核。项目导航包含准备/逐轮切图、标注、待审和导出训练；独立采集、批量任务和审核的主菜单入口收拢至项目，旧链接保留兼容。
- 同一图片可直接上传或复用到有权限的不同项目。平台按内容去重，在各项目中创建独立的图片引用。同一项目重复上传只保留一个引用。
- 共享数据源、复用选择器及其筛选全选使用相同的图片权限。显式复制来源标注时，仍只复制来源项目最新审核通过的标注。
- 标注通过 `annotations.asset_id → assets.project_id` 按项目归属；同图不同项目的标注版本和审核独立。沿用现有项目索引及资产版本约束，无须按项目新建物理表，无数据库结构迁移。
- 同项目支持原图→人→人脸→五官逐轮切图。准备区“切图轮次”留空显示全部，0为原图，1/2/3为对应轮次；全选与列表使用相同轮次条件。每轮更换对应检测模型并选上轮结果，完成后刷新列表。新裁剪记录保存父资产、父文件、区域、模型、轮次、裁剪链和相对根图坐标。历史裁剪记录不批量回写；旧记录缺少轮次时按第一轮显示。
- 全量质量统计修复工时区间逐条扫描和重复读取标注内容。115同批数据只读比较，结果完全一致；统计耗时20.721秒→8.545秒，仍受全量事件读取与聚合影响，不承诺所有接口均为毫秒响应。


项目列表可直接“上传图片”，检测项目还可直接打开“预标注与AI审核”抽屉，固定当前项目，完成创建任务、查看进度/明细、取消/重试及AI转人工预览审核，整个操作保留在项目管理页。新建项目后留在项目列表，由用户选择上传、采集或复用数据。关闭上传弹窗仍继续处理当前队列；上传中禁止切换上传目标，离开页面或刷新仍会暂停前端传输，重选相同文件可续传。

已有图片无需重复上传。项目列表的“从已有图片集添加”直接打开现有复用选择器，选择图片集、筛选图片，勾选或“选择当前筛选全部图片”后添加到当前项目；也可在“进入项目 → 复用已有数据”操作。默认仅增加项目引用，项目已有图片排除重复添加；按需选择复制来源项目已审核标注。此入口于2026-11-04在115单文件热更新，保留项目上下文，未重启后端或进行真实数据关联测试，验收见 `docs/testing/project-collection-entry-2026-11-04.json`。

“进入项目”提供完整图片管理、数据拉取、复用已有数据、标注、审核及导出训练。项目导航另提供预标注、管理员待审和质量分析入口，切换时保留当前项目。共享数据源从项目列表的次级入口进入，原图库和图片集继续作为共享资源，不迁移或复制原图。批量预标注/AI审核沿用现有检测项目接口，其他任务类型可在项目列表上传。

数据拉取也提供“新建项目”和“预标注与AI审核”：新建后直接选中并用于后续拉取；设备抓图页的新建项目可作为新计划的默认项目，不修改已有计划。任务抽屉在父页面中打开，保持数据拉取查询结果与设备选择。未选择项目或所选项目不是检测类型时，不能发起检测批量任务。

旧台账定时计划重新启用时也以保存的项目、图片集和分辨率为准，原本仅下载的计划不会被当前新建项目污染。保存配置的租户必须与当前身份一致。

## 登录与数据拉取入口

曾出现数据拉取内嵌窗口登录后显示主系统首页、形成双层导航：原因是401只重定向了iframe自身，登录后又在iframe里进入首页。过期认证现在跳转顶层登录，管理员登录成功回到原业务路径及项目参数；普通用户仍按权限进入标注页。返回路径只允许安全的本站路径。

登录时长默认24小时（86400秒），签名到期和接口`expires_in`使用同一配置。115已于2026-11-03完成发布并设置`JWT_EXPIRATION=86400`；已验证新签名的有效期为86400秒。JWT密钥未轮换，已有凭证的`exp`不能延长，需要重新登录获取24小时凭证。

Vite开发服务与预览服务将`/smarteye`文档请求送到主应用入口，保留项目查询参数；`/smarteye/index.html`和模块请求继续加载独立SmartEye应用，避免文档路径被解析为同名目录下的TypeScript模块。

## 数据复用

在项目图片页点击“复用已有数据”，选择来源项目、标注标签、场景及可选审核通过状态，筛选结果和全选使用同一条件。可以只引用图片，也可以选择复制来源项目最新已审核标注。图片添加为目标项目引用，复制的标注版本独立，来源项目后续编辑不改目标副本。

复制要求任务类型相同且数据能通过目标项目格式校验；目标已有任何标注版本时保留并计冲突。来源未审核通过的标注不复制。检测框/分类标签按目标项目标签取匹配内容，完全不匹配时图片保持未标注，不能因过滤变成负样本；原本明确的负样本保持单独处理。标签范围发生变化的副本待审核，完整兼容的副本可沿用来源审核。审核证据记录来源项目、标注ID、版本、审核人和时间，不生成新的人工审核操作，也不计作人工标注产出。

复制支持检测、分类、描述和向量项目；原图库可跨项目复用，项目私有裁剪图和分割标注本轮暂不复制。不能将裁剪框坐标直接套回父原图。

项目直接上传只关联上传回执 `image_upload_items` 中本批真实图片ID；重复原图也可关联。不会把整图片集旧图带入。关联失败可继续重试或从已完成上传记录添加到当前项目；已有标注保持。

直接上传、断点上传和SmartEye正式归库均按原图字节SHA256复用同一`images/<hash>`文件，不同名称、图片集和项目只增加引用。SmartEye任务目录使用硬链接；上传分片/组装文件和导出ZIP属于暂存或交付文件。本轮不清理历史物理文件，也不把重编码后的相似图当作相同字节图片。

## 管理员待审

独立入口为 `/review-queue`，可筛选项目。每条显示项目、图片名、任务类型、原因和版本，UUID作为辅助信息；可进入来源任务或打开审核工作台，并返回原管理员待审队列。

普通标注审核与AI转人工待审保留各自状态规则。无原图、版本变化或未保存候选仍不能批准；旧候选可驳回，已删除图片的队列项仍显示项目归属。

## 模型连接与分析

模型列表区分启用状态和连接状态。管理员打开列表时最多三路并发检测；结果按配置版本保存在线、离线、原因与时间。配置修改后重新检测，旧配置的迟到结果拒绝回写。检测只验证接口、后端就绪和模型ID，推理效果仍需试运行。

质量与效率分析修复全租户大数据量的SQL参数超限：使用SQL子查询代替把全部ID展开为参数。已用33,000条隔离数据复现回归，并对115的57,009条标注、131,433条事件完成只读验证。全量统计约16.4秒，尚未重写Python聚合做进一步提速。
