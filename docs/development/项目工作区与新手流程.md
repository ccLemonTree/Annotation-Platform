# 项目工作区与新手流程

2026-11-06：保留钴蓝主题和既有数据能力，统一项目内的操作入口。

## 操作路径

1. 项目列表仅展示项目、任务类型、数据量和审核进度。点击整张卡片进入项目；新建只需要名称、任务类型，创建后进入数据页。
2. **数据**：上传到项目、复用已有数据、定时抓图/数据拉取；筛选和批量管理默认折叠。处理数据/检测切图进入项目的标注准备区域。
3. **标注与审核**：开始/继续标注、AI预标注与审核、AI转交待审，以及相应项目的目标属性分析。数据处理与标注准备按需展开；已有结果在下方筛选审核。修改审核筛选或刷新不会清空处理表单。
4. **导出与训练**：导出/冻结标注，直接创建、查看和管理本项目训练任务。只有平台冻结版本可创建或修改训练配置；服务器已有数据路径不再是训练来源。保存后仍需预检查并手动启动。
5. **测试与评估**：快速测试可直接选择本项目图片，也可上传文件；数据集评估固定本项目真值，测试与评估记录按项目查看。任务类型随项目固定，无需重复选择。当前支持检测、图片描述和向量检索；分类与分割显示未支持说明。
6. **项目设置**：名称、类别和成员分配；高级设置包括标注范围。保留类别映射和历史/冻结数据保护。删除项目放在独立折叠区域。

项目标签尚未配置时，标注页引导管理员设置类别，普通成员联系管理员。项目管理、成员分配和训练仍仅管理员可用，不改变后端项目/租户授权。

目标属性分析页只展示配置摘要；“查看 / 编辑配置”和分析区域的“修改目标标签”打开大弹窗。长表单在弹窗内滚动，标题和保存操作保持可见。关闭不提交配置，重新打开保留当前页面草稿；刷新或离开页面前仍需保存。模板命名在同一弹窗内展开，保存模板与保存项目配置分开。

快速测试只展示模型输出，不代表准确率，也不会修改项目图片和标注。检测评估使用已确认标注或冻结包的 val/test 划分；描述与检索评估固定已审核数据。训练数据与评估数据是否独立仍须核对。项目测试沿用管理员权限。

## 标注与恢复

- 项目内每个检测标签使用不同颜色，画布、框列表、模型预测和审核预览保持一致。未知标签采用确定性颜色兜底，并仍显示名称。
- 显式按钮切换“标注切图（或标注图片）/原图”。选择在当前浏览器标签页内保持，换图和刷新不会重置，直到手动切回。原图只读显示来源及裁剪位置；切换保留草稿，保存仍针对当前标注图片。
- 质检开始前确认所选数量、项目图片及标注删除范围；取消不提交，来源原图保留。
- 冻结版本读取失败提供重试按钮；项目固定后无需切换项目恢复。
- 旧 `/projects/:id/prepare` 转入合并工作区并保留操作参数；带 project_id 的旧训练链接转入对应项目导出页，其他旧训练链接转项目选择。
- 用户明确不要求适配旧测试训练任务；没有项目来源的历史任务不补造归属，也不删除记录。
