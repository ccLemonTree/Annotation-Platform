# 智能处理、审核、检索与分析

## 批量预标注和AI审核

管理员从侧栏“预标注与AI审核”进入 `/automation`，点击“创建任务”：

审核完整核心提示词在“模型管理 → 编辑审核模型”保存，任务内“补充审核要求”追加到该核心指令之后。系统固定的类别/框编号与JSON约束仍会追加；解析和自动通过规则不变。详见[提示词编辑](模型服务管理.md#qwen-提示词编辑2026-10-16)。

1. 选择检测项目及任务类型。预标注只选未标注图片；AI审核处理已有标注，保持人工框与标注版本不变。
2. 选择模型管理中已启用的检测模型及OpenAI视觉审核模型，当前可选Qwen3.8-27B。检测模型需要能识别项目类别；不同名称用“类别映射JSON”对应，例如 `{"person":"人"}`。SAM3需保留实际服务要求的提示名，可先复制模型默认参数。
3. 调整检测置信度、IoU、自动通过阈值、外扩比例和补充审核要求。自动通过默认阈值0.9，必须**每个框严格大于**阈值，并且Qwen逐框类别/范围及整图完整性都通过。任一警告、低分、无法确认或有漏标疑问均不会自动通过。
4. 每边外扩默认原框宽/高的20%，超出原图部分裁到边界；只用于审核，不修改保存的检测框。
5. 不填资产ID按整个项目；指定ID可缩小范围，单任务最多10000张。创建后查看进度、明细及证据；可以取消或重试失败/取消项。普通用户可读任务，但不能创建、取消或最终审核。

成功自动审核的正样本直接成为审核通过状态，按原导出规则可用于训练包，无需重复人工审核。模型生成和自动审核各自记录来源，不冒充人工标注/审核次数。

### 负样本如何审核

**所有负样本均由管理员最终审核**，包括人工标记、模型零框和Qwen认为没有目标的图片。零框只是候选，Qwen会按项目全部类别检查整图；Qwen的“无目标”不能绕过管理员。管理员在待审队列查看原图和证据，明确无目标后批准；发现目标则驳回并到工作台补框。

Qwen不确定、无效输出、调用失败或超时时也转管理员。模型检测/图片读取本身失败则记录为失败，可重试。未映射类别保留检测候选，不保存非法标注；可驳回移出队列，或到工作台配置正确类别、人工保存后另行审核。

管理员批准前校验图片内容、项目类别、标注ID/版本与人工审核结论是否仍一致。过期候选不能批准，但可以驳回移出队列，且不会修改后来的人工标注。工作台或旧批量审核API同样不能让普通用户批准负样本或AI转管理员条目。

### 证据与服务限制

任务固定模型版本、参数、类别和原图内容；保存逐框结论、完整性、负样本结论、每轮裁剪坐标和模型来源。取消、人工改框、人工新审核、模型变更或项目类别修改都会阻止迟到结果覆盖。

2026-10-16用户已将Qwen服务调整为每次最多3张图片、16384上下文。平台每轮发送1张包含全部红框/编号的整图和最多2张独立外扩局部图，不再拼接；局部图前的 `Crop #编号` 文字对应原框编号，黄色框标明待审核目标。多框分轮，零框仅发送整图；保留整图1024×768、局部图512×512的等比缩小上限及768 tokens输出预算，证据模板版本为3，不修改远端部署。14项审核回归通过；真实Qwen三图合成请求约6.75秒返回两个框的结构化结论，未写入业务标注。单图超过100框直接交管理员；上下文或图像细节不足不能确认时也转管理员。尚未用独立基准评定误通过率。

服务重启将正在推理的项标为失败供手动重试；已排队项继续。默认2路预标注/审核处理，可通过 `AUTOMATION_CONCURRENCY` 设置1–4；现阶段仅单后端进程，不部署多实例，也不自动对历史项目创建全量任务。

## 图片描述与检索

从 `/image-semantics` 选择图片集或跨页勾选图片，再选择描述模型、Embedding模型，生成描述、向量或两者。每批最多5000张。原图不复制，描述及完整2048维WEMM向量持久保存，支持查看逐图结果、取消与失败重试。

“本批描述提示词”留空使用模型管理中的描述核心提示词；填写时只覆盖本批的描述指令，最多2000字符，不影响Embedding输入。新批次固定所选模型及提示词快照，已有任务和结果不会因输入变化而更新。

生成向量后，选择同一Embedding模型，通过文字或库内图片检索，设置TopK。索引按模型ID、配置版本、维度及预处理隔离；改模型配置后需要重新生成当前空间索引。当前图片变更/删除、配置改变和取消都不会让旧推理写回。

当前用完整向量精确余弦检索，每个查询范围最多5000条当前空间记录，超限明确报错，请缩小图片集；不暗截前5000条。相似度只用于寻找图片，不作为标注正确性证据。Reranker按用户要求不使用。

## 质量与效率分析

从 `/analytics` 按项目和日期查看最新标注的通过/拒绝/待审、类别与负样本分布、人工/模型来源、人工保存/审核、自动生成/审核与返工事件。**流程通过率不等于独立测试集准确率**；当前未实现独立真值评测或图片清晰度等质量评分。

工作台提供“标注计时”和“审核计时”，有真实操作后开始，隐藏/失焦、历史只读或空闲60秒暂停。15秒发送一次短区间，服务端单段最多30秒，重复心跳去重；同一用户跨标签页/模式的区间取并集，避免重复累计。每小时工作量仅统计落在对应活跃时段的人工事件，自动处理不计入人工工作量。

历史数据没有采集过耗时就显示“未采集”，不会按创建时间猜测。离线心跳最多重试2分钟，超过后丢弃并提示；关闭/断网可能损失未提交的短区间。这些时长用于过程分析，不是独立的人力考勤凭证。

## 图片预览快捷键

图片管理及项目“管理图片”中，点击缩略图后按 ← / → 或上一张/下一张切换。沿用当前筛选和排序，按需跨页读取，不扫描整库；首尾禁用，关闭预览取消请求。输入框、其他弹窗和带修饰键的按键不触发切图。并发增删造成顺序变化时关闭预览刷新列表。
