# 大模型与向量验证、效果预览

入口：侧栏“模型验证”和“模型效果预览”，选择“大模型图片描述”或“向量检索”页签。目标检测保留原流程。

## 图片描述

在图片描述项目保存并人工审核描述，再创建验证集。创建时固定图片内容哈希、描述、标注版本和审核人；修改项目不会改写历史真值，可用“更新真值”创建新版本。

选择模型管理中的已启用描述服务，或服务器上的 Swift 模型目录，填写提示词和最大输出 tokens 后启动。结果逐图显示人工参考描述与模型描述，可用左右方向键切图。管理员可标记“描述正确 / 描述错误 / 无法判断”并填写说明；这仅保存在验证结果，不回写原标注。

人工复核通过率 = 正确 / (正确 + 错误)，无法判断和未复核不在此分母，同时展示全部复核数量。自由文本不以字面完全一致判错，也不由受测模型给自己打分。

效果预览可直接上传图片或压缩包、填写提示词，查看描述，不需要参考真值。OpenAI视觉接口支持自定义提示词；旧的固定 `/caption` 服务仍采用该服务本身的描述行为。

## 文搜图与图搜图

在向量项目执行文搜图或图搜图，人工判定并审核匹配关系。创建验证集时固定本次候选图片和已审核正负关系，未审核、无法判断及图片哈希已变化的关系不作为指标真值。单集最多5000张（含独立查询图片）和200条查询。

验证使用新模型重新生成候选及查询向量，仅在本任务内精确余弦排序，不复用历史模型索引或写入业务 Milvus。分别展示文搜图和图搜图的 Hit@1/5/10、Recall@1/5/10 和 MRR；查询可有多个正样本。

- Hit@K：前K张中是否存在已审核正样本。
- Recall@K：前K张包含的已审核正样本数 / 本查询已审核的有效正样本数。
- MRR：本查询第一个正样本排名的倒数，再对有效查询取均值。
- 图搜图按内容哈希排除参考图及其完全相同副本，避免自身命中抬高成绩。
- 正样本向量生成失败、查询向量失败、维度不一致、没有有效非自身正样本时，明确显示排除原因，不伪造为0或纳入完整查询分母。
- 未判定结果保留“未判定”，不自动当误报。当前指标基于已有正样本，不能证明未标注候选都是负样本。

向量效果预览上传一组候选图片，填写文本查询；或选择“图搜图”，填写上传展开后查询图的序号（从1开始）。结果显示Top10排名及余弦相似度。没有人工相关性真值，只展示检索效果，不给出验证准确率。重新预览可更换查询。

## 模型来源和运行

服务来源使用模型管理中的描述/Embedding配置，保留模型ID与修订号。向量必须是支持图像及文本输入的多模态模型；维度从响应验证，最多16384维，禁止零向量和NaN/Infinity。完整向量留后端，接口和JSON报告不返回向量数组。

服务器来源可选已结束的 Swift/WeMM 训练任务及模型目录，或填写已有模型目录。合并模型需含 `config.json`；LoRA checkpoint需含 `adapter_config.json`，并另填基础模型目录。可填 Swift `model_type`（如 `wemm_embedding`），使用已准备的训练镜像，不自动下载镜像或模型。镜像必须包含对应模型的 Swift 适配实现。

模型目录、全部模型文件及可选基础模型按内容固定组合SHA256，启动前重新核对；目录不能含符号链接。一次独立容器加载模型，顺序处理本轮全部图片与文本查询，完成后批量取回结果。图片按RGB、最长边1024、JPEG质量90处理，与现有OpenAI图像请求保持一致。容器无外网、模型只读，限制4核、96GiB主机内存；GPU需明确选择并与训练共用预留/实际占用检查，显存不足会失败，不会自动抢占其他GPU。

保留进度、取消、失败重试、删除和JSON报告。配置或权重变化不能继续旧任务，需新建。重启中断任务后需人工重试。更新真值产生新的验证集；删除任务不删除原图、标注、训练权重。

## 限制与验证

创建验证集本身不证明独立于训练数据。当前描述评估采用人工复核，未包含自动语义裁判、BLEU/ROUGE或通用排行榜。

后端隔离测试覆盖来源、审核边界、文图两种查询、多个正样本、自身排除、维度异常、队列、报告隐藏向量和离线单次加载/逐图错误。页面使用隔离API模拟验证交互。完整真实GPU模型与大批量上传需在本地网络恢复后按实际模型验收；不将模拟引擎测试写成真实模型质量结论。

Swift推理接口依据[官方Embedding示例](https://github.com/modelscope/ms-swift/blob/main/examples/infer/demo_embedding.py)和[TransformersEngine实现](https://github.com/modelscope/ms-swift/blob/main/swift/infer_engine/transformers_engine.py)；兼容已有PtEngine导入入口。
