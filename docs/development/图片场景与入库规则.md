# 场景分类与图片入库规则

## 配置范围

每个图片集独立保存分辨率阈值、分类开关、模型地址/名称及场景名单。新图片集从平台默认模板复制初始规则，此后独立；改模板不影响旧图片集。现有“历史图片”已迁移为自己的配置。

2026-10-16新增“场景分类提示词”，在图片集设置中编辑完整指令（1–8000字符），支持恢复默认后保存。配置字段为scene_prompt，旧配置读取时使用后端默认值；更改不自动重跑已分类图片。系统追加候选场景名单和JSON labels格式约束，未知标签/无效JSON仍会失败并保留原图与旧场景。

场景分类结果属于原图。同集相同内容只保留一条图片引用；同图属于多个集时共享原图、标签、分类状态和结果，不因另一个集的场景名单不同而自动重跑。新增/未分类图首次排队时固定目标集规则，重复图复用已有结果；手动按某个集重新分类，成功后原图场景同步更新到所有所属集，失败保留旧标签。

## 当前配置

模型地址为`http://10.11.12.123:31030/v1`，模型名称为`Qwen3.8-27B`。已通过真实`/models`及带图片的`/chat/completions`请求验证。

平台已启用新图片的后台场景分类，默认场景：山上、河边、工厂、电梯、高位摄像头、低位摄像头。默认分辨率规则是**max(宽,高)>=720**，两条边中任意一条达到720即可；719×719不通过，720×720、720×30和30×720通过。这是尺寸门槛，不是720p质量评分，也不压缩/裁剪原图。

## 使用入口

- 图片管理 → 新建图片集（可先不上传）→ 选择图片集 → 图片集设置：修改分类开关、模型地址、准确模型名称、自定义场景和此集长边阈值。配置持久化，只有管理员可以保存或测试连接；其他用户可读取现行规则。
- 上传到图片库：按目标图片集规则过滤；可单独覆盖本次长边阈值，0关闭过滤；不满足条件的图片跳过，页面显示跳过数量。合法图片先入库，模型在后台处理，不让上传等待逐张推理。
- SmartEye数据拉取：可指定目标图片集，或不指定而按各平台名的图片集归类。选中图片集后可编辑其独立设置；本次阈值留空按图片集，填写则仅覆盖本任务。指定目标时启动任务固定该集规则；按平台名时首次处理该集图片固定规则，后续及重试复用。检测、台账、监听、智搜、工具、选择下载及AI素材/结果的最终图片都经统一保存入口执行。裁剪临时整图只用于生成结果，不作为最终素材分类，裁剪结果正常过滤/分类。
- 图片库：按场景或分类状态筛选。先选择图片集，再多选图片点击“场景分类 / 重试”，可分类历史图片或重新处理失败/已有结果。重新排队保留旧标签直到新结果成功，失败状态和错误信息可在列表查看。

场景支持多标签，例如工厂+高位摄像头。每次推理只接受所用图片集配置名单内的标签；其他图片集复用这张原图已有标签，不强行删除名单外的旧标签，无法确认可返回空数组；模型判断需要按数据质量需求核对。场景与图片集名称、项目的检测类别是不同属性：日期/平台图片集继续保留，场景变化不会修改person等框类别、标注版本或冻结包。

## 状态与恢复

未分类 → 待分类 → 分类中 → 已分类/分类失败。重复上传或拉取同内容复用原图和成功的分类，不重复调用模型。仅新增或未分类图片自动排队；已有图片不会因为保存设置而自动全量重跑。

分类超时、网络/服务错误、非法JSON、未知标签都标记失败，图片仍保留且可用于项目。请求不持有数据库事务；新尝试代号和来源图片集的配置版本防止旧结果覆盖重试或新配置。待分类任务在重启后继续处理；处理中任务在重启后标记中断失败，由用户手动重试。

当前后台分类按单后端进程部署，默认最多4张并发，共享HTTP连接；数据库行锁防止同图被重复领取。可在后端环境设置`SCENE_CLASSIFICATION_CONCURRENCY`（1–16）并重启，这是所有图片集共享的总上限，非每集分别4路。扩展多实例前仍需增加带租约的恢复；没有恢复或重试SmartEye的付费AI生成任务。

2026-10-15真实待分类队列短测：原1并发20秒完成16张，4并发20秒完成39张，约2.44倍，后一窗口无新增失败；这是短窗口而非长期保证。合并前已存在13张模型请求失败，图片保留，可筛选“分类失败”后手动重试。见[本轮验收](../testing/collection-merge-scenes-verification-2026-10-15.json)。

## 接口

| 操作 | API |
|---|---|
| 创建空图片集 | POST `/api/images/collections`；name，相同名称复用现有集 |
| 读取图片集设置 | GET `/api/images/ingest-settings?collection_id=<UUID>` |
| 保存设置 | PUT `/api/images/ingest-settings?collection_id=<UUID>`；classification_enabled、base_url、model、scenes、min_long_edge、scene_prompt |
| 测试模型连接 | POST `/api/images/ingest-settings/test`；同配置对象，返回models与model_available |
| 上传覆盖阈值 | POST `/api/images/batch-upload`；multipart字段collection_name与可选min_long_edge，原数组响应按原图ID去重，`X-Images-Skipped`返回跳过数量 |
| 场景筛选 | GET `/api/images?scene=工厂&scene_status=completed`；每条返回scene_labels、scene_status、scene_error、scene_metadata |
| 排队或重试 | POST `/api/images/scene-classify`；collection_id及image_ids数组，校验图片属于此集，返回queued_count；身份及租户范围校验 |
| SmartEye本次阈值 | 可选请求头`X-SmartEye-Collection`指定图片集；可选`X-SmartEye-Min-Long-Edge`覆盖本任务阈值，未提供按图片集规则 |

不带collection_id的旧配置GET/PUT仅操作新图片集模板，前端不把它作为当前集设置入口。

模型接口按vLLM的OpenAI格式，图片以临时缩略图base64传送，最长边不超过1024；原图仍保留原始字节。使用服务端现有`QWEN_API_KEY`作为可选鉴权，不在浏览器暴露密钥。本轮未添加按模型分别配置密钥。
