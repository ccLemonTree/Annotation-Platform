# 平台操作导航

顶部“搜索平台功能”可按切图、提示词、分类、检索、导出、训练、验证等任务关键词查找入口。

## 上传图片直接看模型效果

进入“模型与算力”→“模型效果预览”（模型管理、模型验证页也有入口），选择检测接口或 YOLO / RF-DETR 训练权重，再选择图片，点击“开始模型预览”。支持 JPG、PNG、BMP、WebP，以及 ZIP、TAR、TAR.GZ/TGZ；点击“选择文件夹”可加入子目录图片，非图片文件忽略，同名图片通过相对路径区分。每批最多 **5000张图片**（包含解包后），上传文件合计 **10GiB**、展开图片合计 **20GiB**、单图 **100MiB**（以页面读取的平台配置为准）。压缩包仍校验路径、链接、加密内容、条目数与展开大小，嵌套压缩包不递归展开。

上传时显示进度，可停止上传请求；文件上传结束后会检查压缩包并准备推理。中断的上传需从头重传；若请求停止时任务已经提交，可从“打开最近预览”继续查看。结果每页20张，页码写入URL并在刷新后恢复。直接叠加检测框、类别和置信度，可关闭叠框查看原图，调整阈值后重新提交。

权重来源可选平台训练任务产物（包含运行中任务已保存的 checkpoint），或直接填写服务器已有权重路径。选择任务后可“刷新权重列表”；未找到权重时会提示等待保存或切换服务器路径。权重和镜像按哈希固定，读取期间变化会失败，需要重新开始预览。默认CPU，可由管理员选择空闲GPU；与训练共享资源占用保护。RF-DETR需填写训练类别顺序，2XLarge沿用许可证确认要求。已实测用户指定的绍兴A100 checkpoint_best_ema.pth（RF-DETR 2XLarge，fire、smoke、star），CPU推理成功。正式验证集评测仍要求训练结束。

预览图片独立保存，不进入图片库或标注项目，不执行描述、分类或AI审核；没有标注真值，不计算准确率、误检率或mAP。刷新后通过“打开最近预览”恢复；失败可重试，运行中可取消，远端停止待确认时保留资源占用。“删除预览”先取消并确认停止，再删除本次上传图片和预览记录，不删除模型权重。

## 手动释放GPU

管理员进入“GPU资源”，选择服务器，在“平台GPU任务与资源预留”中点击“停止并释放”，或在“计算进程”中点击“释放显存”。确认窗口先展示目标和受影响GPU，取消不执行停止。平台任务停止后才解除预留；普通进程可单独勾选超时强制结束。Docker进程会停止整个容器，已保存文件与训练权重保留。Kubernetes进程需从对应工作负载停止。操作后自动刷新占用，其他进程仍可能使用GPU。

## 项目内工作

在“项目管理”选择项目，统一使用项目导航：

1. **图片**：从图片库添加原图，查看当前项目的原图和私有裁剪图。
2. **标注准备**：按需检测切图、批量生成描述或建立检索索引。处理任务提交后自动进入后台队列；已有可用图片时可直接开始标注。
3. **开始标注**：检测/分类/描述项目继续最近的图片；向量项目选择图片描述、文搜图或以图搜图。图片描述不要求生成向量。
4. **审核**：审核图片标注或检索匹配。检索判定自动保存，模型与人工一致自动通过；分歧进入人工复核。
5. **导出与训练**：下载标注包，或进入训练使用平台冻结版本。检测数据先划分并冻结 train/val；图文数据可在训练表单选择来源并冻结。

切图、描述和索引操作已集中到“标注准备”，审核页只展示审核。导出入口集中到“导出与训练”。已有标注/审核地址仍可使用。

## 页面间衔接

- 从项目进入训练，点击“创建训练任务”会预选本项目、平台来源和适用训练器；仍需人工填写服务器与GPU等配置、保存、预检查并确认启动。
- 检测项目从“导出与训练”进入模型验证，创建验证集时预选本项目。验证数据须独立于训练数据；现有验证集和任务仍完整展示。
- 检测准备页可直接进入当前项目的预标注/AI审核；模型配置完成可返回当前项目准备页。
- 检索工作台的模式、历史查询和查询页码记录在URL中，打开单图编辑后返回可恢复；单图审核上一张/下一张保留审核来源和筛选。
- 训练详情可下载产物，并进入模型验证或对应服务器SSH调试；SSH页可返回该服务器GPU页面。
- 各功能标题下提供关联功能入口。旧图片库生成历史独立标识，不再显示“工作概览”。

未保存的单图标注仍会在离开前提示，删除确认、审核规则和训练启动保护保持原有行为。

## 训练效果分析

训练完成后看效果：“模型训练”→任务行“效果分析与对比”→选择更早完成的模型（可不选）→“读取指标并对比”→选择大模型、编辑提示词→“大模型分析并保存报告”。重新打开会载入最近的报告；只看框与置信度用“模型效果预览”，需要独立验证集评测用“模型验证”。

## 上传完成但看不到图片

“图片管理”→“上传图片”→“最近上传与续传记录”，查看实际入库、已存在、尺寸过滤、无效和忽略数量。传输100%仅说明文件已上传，处理完成也可能因规则过滤而没有图片入库；记录显示本次实际使用的尺寸阈值和目标图片集，可点“查看图片集”定位。

若因尺寸不足被过滤，需要保留这些小图时，将“本次上传长边阈值”填写为 **0**，重新选择原ZIP并点击“开始 / 继续上传”。这只覆盖本次导入，不修改图片集默认规则。局域网HTTP上传保留分片校验与续传，无需改用localhost。

## 删除图片集（文件夹）

“图片管理”→在“全部图片集”筛选中选择目标→“删除图片集”。确认窗口核对整个图片集的图片数量，不受当前场景、文件名或分页筛选限制。

删除图片集，并从图库删除仅属于该集、且未被项目使用的独占图片；被其他图片集或项目使用的图片保留。窗口显示预计删除/保留数量，提交时重新检查引用并显示实际结果。删除后回到全部图片集，项目标注和已冻结数据保留。

有未完成上传时先完成或在上传窗口清除对应记录；有待处理/正在运行的场景分类时等待完成。原始文件沿用平台的存储保留策略，此操作不直接清理磁盘文件。
