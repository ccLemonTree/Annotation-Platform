# 独立图片库与标注项目

图片属于平台图片库，标注项目只使用图片。默认流程：**上传／SmartEye拉取 → 独立图片库筛选 → 添加到标注项目 → 标注、审核、导出**。

上传窗口现支持图片、文件夹和ZIP/TAR（含tar.gz/tgz），采用8MiB分片。断开或刷新后重选相同文件与目标规则可续传；导入沿用图片集过滤、内容去重和共享场景。操作与限制见[文件夹与压缩包上传](文件夹与压缩包上传.md)。

## 图片集名称

图片集按名字组织图片，例如1013、1014或平台名称。上传窗口可输入新名称或选择已有图片集，同名继续追加；界面默认当前筛选、上次有效选择或已有第一集，没有已有集时主动命名。兼容上传API未传名称仍用上海日期MMDD。库中“图片集”筛选可按名称搜索并显示数量。已有图片多选后点击“加入图片集”，可归入指定名称。

SmartEye检测、台账、监听、智搜和工具下载按真实平台名建立图片集；多平台任务分别归类。详情页下载也携带来源平台名。AI结果／素材使用AI生图／SmartEye素材；没有平台信息时明确显示SmartEye（未提供平台），不猜测来源。同一图片可以属于多个图片集，仍共用原图和各项目独立标注。

## 使用方式

1. 打开“图片管理”，默认显示独立图片库。上传不要求项目；SmartEye成功下载的最终图片也进入这里。可以按图片集、场景、分类状态、名称、来源、首次入库批次／拉取任务ID、入库时间筛选。
2. 勾选图片，点击“添加到标注项目”，选择项目。每页可选20／50／100张，翻页保留勾选；“选择当前筛选全部图片”选择所有匹配图片，不受当前页限制。修改筛选会清空勾选，“清空选择”也可手动重置。多份图片可添加到同一个项目。
3. 打开“项目管理 → 管理图片”，进入独立的项目图片页`/projects/<项目UUID>/images`。页面显示项目名称、面包屑和项目自己的标注／审核状态，侧栏保持选中项目管理。
4. 在项目图片页点击“从图片库添加”，抽屉提供与图片库相同的筛选、20／50／100张分页及跨页选择；底部分页和提交按钮固定可见，图片表格单独滚动。项目已有图片不可勾选，“选择当前筛选全部图片”也排除它们。成功后关闭抽屉并刷新当前项目；失败保留剩余选择供重试，取消不写入，也不跳转。
5. 点击项目图片的“标注 / 审核”进入工作台；顶部“返回 <项目名> 项目图片”返回原项目。新建项目成功也直接进入其图片页，再选择图片。

图片管理固定为独立图片库`/assets`，不再通过下拉框切换成项目视图。从图片库添加到项目后仍留在图片库，并显示“查看 <项目名> 项目图片”入口，由用户明确跳转。旧`/assets?project_id=<UUID>`自动转到对应项目图片地址，刷新及后退保持页面含义。

添加项目、加入图片集、场景分类超过1000张时，界面每批最多1000张依次提交。成功批次立即生效并移出选择；某批失败即停止，剩余选择保留，原按钮可继续重试。全选读取失败保留此前选择。操作进行中请勿刷新或离开页面，刷新不保留勾选；分批操作不是整批事务，失败不会撤销已成功批次。分类仍需先选择已启用分类的图片集。

同一张原图可以用于多个项目。添加项目只创建使用记录，不复制原图；重复添加相同内容不会增加项目计数。不同项目的类别、标注、版本、审核互相独立。类别同步只修改该项目的最新标注，不修改其他项目。

SmartEye仍保留独立页面，“仅下载到本地”无需项目，下载结果进入图片库；“直接用于标注”先登记图片库，再自动添加到所选项目，无需再次手工导入。裁剪所用临时整图不作为最终素材登记，输出裁剪图正常登记。

## 标注与审核按项目

侧栏“标注与审核”固定进入`/annotations`的标注项目列表，显示各项目图片数、待标注、已标注及已通过数量。选择项目后进入`/annotations?project_id=<UUID>`，只查询此项目的最新标注，列表显示图片预览、名称、目标数、版本、状态及更新时间。未标注图片从“查看项目图片”进入；没有标注的项目保留明确开始标注入口。

审核状态、页码和每页数量保存在URL，改状态回到第一页。读取失败就地重试，不显示上一个项目的内容。通过“打开标注 / 审核”进入画框工作台后核对图片与框，再通过或驳回；已取消JSON弹窗和列表中未看图片的快捷审核。切图后返回仍保留原项目和筛选；从项目图片页进入的工作台仍返回项目图片。

## 删除与历史

项目视图的“移除”只删除该项目的使用记录及其标注／审核，不影响原图目录和其他项目。删除整个项目同样保留图片库。图片库中已被项目引用的图片不能删除，需先移除对应项目引用；当前删除目录记录仍保留物理文件，供SmartEye和冻结包使用。物理无引用文件清理尚未实施。

冻结包保持当时的图片、类别、标注版本和审核记录；目录管理不改写旧包。内容哈希用于租户范围去重，相同内容再次上传／拉取复用原图片记录，保留首次入库的文件名、来源和批次，并保留每次指定的图片集归属；各SmartEye任务的文件记录仍保留。

## 数据结构与接口

`images`是独立图片目录；`assets`保留为项目使用记录，新增`image_id`引用。已有asset_id仍用于标注、审核、版本与导出，不需要更改历史ID。保留旧元数据字段兼容已有调用方，原图路径仍指向统一存储。

| 操作 | 主API |
|---|---|
| 分片/文件夹/压缩包上传 | `/api/image-uploads`，见[上传接口](文件夹与压缩包上传.md#接口)，无项目参数 |
| 兼容独立上传 | POST `/api/images/batch-upload`，multipart的files和collection_name，仅图片，无项目参数 |
| 筛选图片 | GET `/api/images`，q、collection_id、scene、scene_status、source_type、batch_id、created_from、created_to、page、page_size（最大100） |
| 筛选全部ID | GET `/api/images/selection`，与列表相同筛选、不分页；可带exclude_project_id排除指定项目已有图片；返回image_ids和total |
| 图片集列表 | GET `/api/images/collections`，返回id、name、image_count |
| 加入图片集 | POST `/api/images/collections/assign`，name、image_ids；返回collection_id、added_count |
| 原图预览 | GET `/api/images/<image_id>/content`，要求Bearer Token |
| 添加项目 | POST `/api/images/associate`，`{"project_id":"项目UUID","image_ids":["图片UUID"]}`；返回added_count和asset_ids |
| 项目已使用图片 | GET `/api/assets?project_id=<UUID>`，每个项目有独立使用ID和标注状态 |
| 移除项目引用 | DELETE `/api/assets/<asset_id>` |
| 删除目录记录 | DELETE `/api/images/<image_id>`；使用中返回409 |

每个添加请求先校验全部图片和项目范围，再同一事务建立引用。单请求最多1000张，重复ID去重，并发添加不重复计数；不存在或越权返回404。界面的大批量选择按上述规则拆分多个请求。旧项目上传API继续兼容，同时登记图片库。全局图片总数、入库趋势和原图字节统计按图片库去重，项目标注／审核按项目使用记录统计；dashboard的assets_overview另有project_references计数，pending/in_progress分别为未使用／已使用的图片。
