# 模型服务管理

侧栏“模型管理”统一配置推理服务，与训练产物表分开。管理员可新增、编辑、删除、启停和连接测试；普通登录用户可查看启用模型并试运行。所有接口按当前账号范围校验，鉴权密钥不下发浏览器。

## 配置与试运行

- URL包含服务根路径，例如OpenAI服务使用`/v1`；ENDPOINT填写`/chat/completions`或`/embeddings`，不要再次重复`/v1`。
- `model_service`协议使用multipart字段`image`；检测可配置置信度、IoU和labels提示，解析`detections:[{class,bbox:[x1,y1,x2,y2],score}]`。平台转换成原图像素的x/y/width/height，越界裁到图片范围并提示，非法结果拒绝。
- SAM3的检测提示在模型配置“类别 / SAM3检测提示”逐项设置，例如`sam3_Person`。配置类别映射可把服务类别对应成项目习惯名称；YOLOv26默认把`26_fire/26_smoke/26_hotwork`映射到`fire/smoke/hotwork`。
- OpenAI描述和Embedding传入缩放后的图片及可选文本，Embedding试运行只显示维数和前8项，不回传全部向量。当前服务实测2048维；这不是向量索引或相似图检索功能。
- 超时可设1—180秒；HTTP错误、无效结果、超限响应和配置变更会拒绝本次结果，不写标注。连接测试只检查接口/模型ID/后端就绪，模型效果需要另用样本评估。
- 鉴权填写环境变量名称：`QWEN_API_KEY`、`EMBEDDING_API_KEY`、`RERANKER_API_KEY`，或`MODEL_API_KEY_`开头的专用变量；在后端环境中设置具体值并重启，不把密钥填写到URL或提交代码。

试运行选择图片库图片，或填写项目图片asset ID；仅预览，不保存描述/向量或生成标注版本。

## Qwen 提示词编辑（2026-10-16）

管理员进入“模型管理 → Qwen3.8-27B → 编辑”，在 OpenAI Chat 协议下可编辑完整的**描述核心提示词**和**审核核心提示词**，每份1–8000字符。分别支持恢复默认；恢复只改变当前输入，点击“保存模型”才持久化。其他视觉对话模型同样按协议使用这些配置，不依赖模型名称匹配。

描述核心提示词用于单图试运行、标注工作台预测和批量图片描述。单次输入或“图片描述与检索”的“本批描述提示词”非空时覆盖该次/批描述指令；留空沿用模型配置。Embedding模型和FastVLM接口不使用Qwen的核心指令。

审核核心提示词用于预标注后审核和已有标注审核；创建任务的“补充审核要求”追加到核心指令之后。系统再追加项目类别、全部框类别/编号、本轮编号和JSON输出约束。逐框覆盖、合法JSON、负样本必须人审、严格置信度阈值等仍由代码校验，不通过编辑指令改变这些规则。无效输出不会自动通过。

保存模型后修订号递增，已有任务固定原配置快照；版本变化会阻止旧任务采纳结果，需按新配置新建批次。已保存描述、标注及审核结果不会自动重算。场景分类提示词在“图片集设置”独立编辑，不随模型管理的描述/审核提示词变化。

已有环境先备份并运行019增量迁移，仅增加model_services.chat_prompts JSONB；旧配置在读取时展开默认值，不改旧模型修订号或任务快照。默认值接口GET `/api/model-services/prompt-defaults`需登录；模型GET/POST/PUT增加`chat_prompts:{caption,review}`，省略或空对象使用默认值。创建新环境仍用既有安全空库初始化。

## 标注工作台

右侧选择检测/描述模型并点击“预测预览”。检测结果会叠框展示；不属于项目的类别须明确映射后才能应用。“应用到草稿”替换当前全部框，可撤销；人工核对后仍按原有手动保存/切图自动保存机制形成待审核版本。描述只能查看，不会生成框。未检测出目标不能据此自动确认负样本。

切图、选择其他模型、进入历史版本或禁用编辑时，迟到结果不会应用到新图片。现有人工框和服务器历史不会由试运行直接改写。本轮不包含批量预标注队列、多轮自动审核、置信度校准或模型效果验收。

图片集设置可从模型管理复制兼容OpenAI描述模型的地址/模型ID，复制后仍是该图片集独立配置，不随模型管理后续编辑自动改变。场景分类当前复用全局QWEN_API_KEY，使用其他鉴权变量的配置不能直接复制；原手动配置仍可用。

## API

前缀`/api/model-services`：GET列表、POST新增、POST`/defaults`幂等补充、PUT/DELETE`/{id}`、POST`/{id}/test`、POST`/{id}/predict`。预测请求必须仅包含`asset_id`或`image_id`其中之一，可附`prompt`。返回配置版本、类型、框/描述/Embedding摘要与警告；模型配置本身不在训练`models`表中。
