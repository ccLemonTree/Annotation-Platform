# 检测与属性预标注的正确范例

先在项目中手工标注一张图片并保存，创建预标注任务时选择为“正确范例”。大模型会收到范例原图和对应正确标注，以及另一张待处理图片。范例用于本批推理，不会训练或修改模型，也不参与本批待处理。

## 目标检测

进入检测项目的“预标注与AI审核 → 创建任务”，任务类型选批量预标注，勾选“大模型按正确范例预标注检测框”。选择已启用的OpenAI视觉大模型，再选择一张正确范例。选择器显示人工类别与框位置，可预览原图叠框，也可另开标注页修改后刷新列表。

提交后大模型按范例标准为其他未标注图片生成检测框。坐标在模型输入输出中按宽高归一化为0至1000，再校验并转换到原图像素。非法类别、反向/越界坐标、无效JSON或截断结果不保存。大模型没有校准置信度，所有这类结果均进入人工待审；零框仍须管理员最终核对，不能自动当成已确认负样本。

普通YOLO、RF-DETR等检测服务继续使用原有入口；只有选择“大模型按正确范例”时，图片与标注才作为视觉对话范例发送。

## 目标属性

进入描述/向量项目的“目标属性分析”。手工填写一张目标图的属性并保存，再在“检测切图并预标注属性”或“大模型预标注属性”中点击“选择正确范例”。预览并确认人工属性，点击“使用此范例”。模型会接收范例图片、正确属性JSON和待处理目标图片，检测后的逐目标子批次也继承此范例。

无法判断的属性仍为null并说明原因，不得复制范例的车牌、品牌、颜色等值。可随时清除范例，创建无范例的新批次。

## 范例条件与版本

- 仅可选择当前项目的最新、已保存、未驳回人工标注；模型尚未人工修正保存的结果不能直接冒充人工正确范例。
- 类别/属性必须符合当前项目配置；历史不兼容标注显示提示并禁用选择。检测范例最多100框。
- 选择器支持图片名称搜索、分页、刷新及大图标注预览。点击“使用此范例”即确认其正确，不要求额外审批。
- 批次固定范例图片哈希、标注ID/版本和审核基线。推理前和写回前均检查；范例改标、驳回、删除或内容变化后，旧批次停止写回，需重新选择并创建。
- 仅发送这一张范例和当前待处理图；不发送整个项目图片。范例选择和任务创建沿用管理员及项目权限，不改变普通用户人工标注权限。

范例只提供判断标准，不能保证大模型检测或属性识别准确。推理结果仍需人工核对。
