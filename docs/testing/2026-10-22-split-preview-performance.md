# 划分预览耗时优化

## 复现与修改

运行日志记录该项目预览耗时191.804秒才返回200，超过前端原120秒超时；原实现串行读取、SHA256校验、图片解码和pHash计算，随后用NumPy逐对计算汉明距离。界面只有禁用状态，没有等待提示。

- 预览图片校验改为最多4个线程并行，每个文件仍核对SHA256、尺寸并验证图片；图片文件在各线程内关闭，不保留全尺寸图片。
- pHash在两两比较前一次转换为整数，用XOR/bit_count计算等价汉明距离，保留颜色阈值和全部近重复配对，不抽样或跳过检查。该共享函数也用于冻结包检查。
- 界面显示检查张数、已等待秒数和明确的工作提示；请求结束后恢复控件。预览请求超时调整为300秒。
