# 训练权重验证批量结果回传

用户确认取消当前烟火验证后，将 `checkpoint_validation.infer` 的逐图 SSH 回传改为整批结果包回传。适用于模型验证和上传图片效果预览选择训练权重的入口；常驻模型服务 HTTP 检测、预标注、项目图片处理不受影响。

## 实现

- `checkpoint_executor.py` 的 `results` 等待容器退出后，按本轮输入 manifest 打包全部单图结果。运行时每次在远端等待最多 20 秒再向平台报告尚未完成；不会为每张图片建立通信。
- 结果包包含原有 owner 身份和单图 JSON，通过已有 ssh-manager 下载接口一次传输。校验 SHA256、文件大小、任务/执行轮次/权重身份、UUID 文件名以及本任务待处理样本覆盖范围后，原子发布到本地 `.backups/validation-results/<execution>/`。
- 后续逐图校验、评价、入库直接读取本地结果，继续复用原队列的权限、取消、原图哈希及版本检查。单图推理错误只影响该图；整包异常按批任务失败处理，避免为每张图反复下载无效包。
- 容器中途退出时，有结果的图片继续保留，缺少结果的图片获得明确错误，不能当作空预测。
- 远端停止确认后清理当前执行轮次的本地结果缓存，其他任务目录不动。未改变权重推理、置信度、类别映射或指标算法。
