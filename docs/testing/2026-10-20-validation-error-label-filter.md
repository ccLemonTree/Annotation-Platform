# 按标签筛选漏检和误报

逐图结果的“错误类型”旁增加“标签”筛选，选项来自验证集冻结类别。组合筛选、分页、刷新和当前标准/目标检出模式共同生效，切换或清除标签回到第一页并关闭旧图片预览。总体报告指标和完整 JSON 报告仍对应整个任务，不因列表标签筛选而改写。

接口 `/api/validation/runs/{id}/items` 增加可选 label 参数。漏检按当前评测结果 unmatched_truth 对应的真值标签筛选，误报按 unmatched_predictions 对应的预测标签筛选。不是简单检查图片中是否出现某标签：smoke 已匹配而 fire 漏检的图片不会进入 smoke 漏检列表。分数低于工作点和已合并重复预测按当前评测规则处理。无错误类型时，标签仅限制图片内包含的类别；正确筛选仍沿用“整图无误报和漏检”的条件。

列表增加漏检标签和误报标签列；预览显示各标签数量。漏检真值框用红色实线及“漏检”标识；低于工作点的预测框用灰色及“低分”标识，保留原始低分预测以供复核。未改工作点、IoU、合并规则或真值。
