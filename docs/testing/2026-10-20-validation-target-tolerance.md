# 验证报告按目标检出判定

用户要求：框无需完全一致，位置接近的同类检测算正确；同一处烟火的多个同类预测框合并为一次正确检出。

## 判定与范围

验证报告默认“目标检出（合并重复框）”，位置容差 IoU 默认 0.3，可调整。先按分数顺序将同类别预测与真值一对一匹配；剩余预测如果与已匹配的同类真值 IoU 也达到阈值，记录为 ignored_duplicates，不增加 TP 或 FP。错类别、明显偏离、未检出的独立目标继续统计 FP/FN。单个预测不能重复匹配两个真值，负样本上的预测不能因合并而被算成正确。

报告可切回“标准框匹配（原任务参数）”。P/R/F1、分类别计数、混淆矩阵、错误筛选和叠框按照当前视图计算；标准 AP 单独显示并维持原算法，不使用合并后的预测计算 AP。

接口在详情、逐图列表、下载报告上接受 mode=target / target_iou=0.3。默认仍是 standard，兼容原调用。业务汇总通过 target_metrics 返回，报告提供 evaluation_view；业务逐图结果另保留 standard_evaluation。只重新计算存量预测，未改数据库表、原任务参数、真值、原始预测或已存储的标准评测。计算逻辑复用 detection_metrics，原标准模式默认行为不变。

叠框展示当前 TP/FP/FN 和合并重复框数量，隐藏已合并重复框；JSON 报告保留全部原始预测与合并索引。
