# Qwen 可编辑提示词 Implementation Plan

**Goal:** 平台管理员可查看、编辑、保存并恢复 Qwen 场景分类、图片描述和 AI 审核的核心提示词。

**Architecture:** 模型配置新增 chat_prompts JSONB，描述/审核各保存一份完整指令；图片集现有 JSON 配置新增 scene_prompt。默认值由后端统一提供。单次描述提示词优先于模型默认值；审核任务保留补充要求。系统追加动态类别、框编号及 JSON 输出约束，原有响应校验和自动通过规则保持。

**Tech Stack:** FastAPI / Pydantic / SQLAlchemy / Alembic / React / Ant Design。

默认按现有管理员编辑权限、租户隔离和配置修订机制执行。提示词变更不修改已存结果；旧任务继续使用快照并遵循既有修订变化拒绝采纳机制。单份核心提示词最多8000字符，不新增依赖，不调整模型部署或调用并发。SmartEye验证码使用Qwen3-VL-8B，AI生图使用其他协议，不属于本次Qwen3.8推理范围。

1. 核对调用链并编写隔离失败测试：模型/图片集持久化、权限、默认值和验证；实际推理请求包含配置指令；输出无效仍拒绝。
2. 后端接入：019仅增model_services.chat_prompts，默认兼容旧配置与旧快照；统一默认接口；接入单图、批量描述、审核、场景分类。
3. 页面接入：模型编辑中描述/审核核心指令与恢复默认；图片集设置中场景指令与恢复默认；批量描述页开放单批覆盖；已有审核补充要求明确用途。
4. 验证：相关后端回归、隔离迁移、前端构建/定向lint、浏览器编辑/保存/失败保留/恢复/小屏。记录API夹具与真实服务验收边界。
5. 本机启用：核对活动任务与监听归属，先备份配置并验证迁移只新增列，再重载后端。验证实际只读配置接口；不运行真实模型推理或批量任务。
