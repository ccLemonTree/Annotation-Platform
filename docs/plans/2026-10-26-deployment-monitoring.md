# 模型下发SSH与实时日志

本地开发、隔离测试及构建通过后更新115；正式数据库及远端服务不用于写入测试。

1. 复用SSH终端，允许管理员选择ssh-manager服务器；按实时配置白名单校验，配置/权限变化时断开。
2. 目标和记录增加只读日志入口：更新阶段、Docker拉取、K8s Ansible预分发及指定实例运行日志。仅从已保存目标派生路径/命令，不接收任意命令或文件路径。
3. 打开日志面板后每次请求完成再等待2秒刷新，可暂停、手动刷新、切换实例；关闭或切换时取消请求，失败保留旧日志并明确提示。
4. 先验证失败用例，再实现；覆盖权限、租户、日志截断与脱敏、实例白名单、符号链接、终端兼容及取消刷新。构建、浏览器隔离验收通过后再更新115并做真实只读验收。

默认管理员使用，单次只看一个实例的最近200行、最多64KiB；不新增依赖、数据库迁移或后台自动生效。
