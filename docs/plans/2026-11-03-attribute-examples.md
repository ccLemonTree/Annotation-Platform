# 检测与属性大模型预标注：正确范例

目标：人工标注并保存一张图片后，可在本批预标注选择为正确范例，把图片和结构化属性一起传给大模型。

约定：检测项目和属性项目共用范例选择及版本保护。范例必须是同项目最新人工标注、未驳回、类别/属性定义与当前配置一致；选择范例即确认正确，不新增审批步骤。范例不参与本批待处理图片。

复用ProjectWorkJob.options及AutomationJob.config保存范例图片哈希、标注ID/版本、框/属性与审核基线；不新增表、不复制业务图片、不训练模型。推理包含范例user图片、assistant正确JSON、目标user图片；禁止照抄范例的坐标和属性值。

检测项目新增“大模型按正确范例预标注检测框”，选择OpenAI视觉大模型；使用0至1000归一化坐标传递范例和返回框，校验后转为原图像素。全部范例大模型检测结果保留未校准置信度警告并交人工审核，不绕过负样本审核。已有常规检测模型预标注保持原行为。

步骤与验收：
1. 先写失败测试，覆盖两图消息、范例排除、权限/配置/来源校验、范例改标与删除时的拒绝写回。
2. 接入范例列表、批次快照、检测子批次继承、推理输入和提交前核验。普通无范例批次保持原行为。
3. 页面支持选择/预览/清除范例、手工标注入口和刷新；队列显示范例版本。浏览器mock验证实际提交和预览。
4. 本地隔离回归与前端构建；通过ssh-manager检查115活动任务，在候选目录验证。活动任务未完成时不覆盖正式源码或重启。
