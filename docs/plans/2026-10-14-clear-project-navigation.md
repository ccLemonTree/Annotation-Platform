# 项目与图片导航简化

目标：始终明确当前位置、操作目标和返回位置，不在同一地址暗中切换图片库/项目含义。

1. 固定图片库为/assets，项目图片为/projects/:projectId/images；旧/assets?project_id链接兼容跳转。项目侧栏高亮、面包屑和项目名保持一致。
2. 项目内“从图片库添加”打开选择抽屉，按图片集/文件名选图，已经使用的图片标记并禁选；添加成功留在项目，失败保留选择。复用现有目录/关联接口，不改数据结构。
3. 图片库不提供切项目下拉。添加到项目后留在图片库，显示目标项目及明确的查看入口。项目入口、概览和标注返回统一使用固定项目地址。
4. 浏览器先复现旧跳转问题，再检查项目入口、抽屉成功/失败/取消、库中添加反馈、标注返回、旧链接、后退/刷新及窄屏；写入拦截，不制造真实业务记录。
5. 双入口构建、编辑器和已有界面回归，核对业务库只读快照不变并更新操作说明。
