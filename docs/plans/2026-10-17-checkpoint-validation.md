# 训练权重验证实施

目标：验证集默认直接运行 YOLO / RF-DETR 训练权重，不要求部署推理服务。管理员可选平台训练产物或服务器已有权重，保留现有人工真值、逐图叠框、指标和报告。

实现：复用validation_runs.model_snapshot JSON记录权重/镜像哈希、服务器修订和独立执行轮次，不新增表。通过既有ssh-manager桥上传校验过的验证图片ZIP；独立、禁网Docker批任务只加载一次权重，按原图输出预测文件。现有单消费者逐图接收并计算指标；取消/重试按执行轮次隔离。默认CPU，可明确选择空闲GPU。训练启动与验证预留共享事务级GPU锁并检查双方占用，不抢占在线任务。

1. 先补权重请求、租户/权限、快照固定、预测接入、取消迟到/重试和资源互斥测试，确认旧实现失败。
2. 接入权重元数据检查、远端独立批执行、类别顺序/映射校验和现有worker；原服务模式API兼容旧任务。
3. 默认界面改为训练产物/服务器权重选择，配置CPU或单卡GPU，结果展示权重来源；训练任务的活动产物不作为已完成权重候选。
4. 隔离后端/远端执行器/浏览器检查，构建和相关回归；通过ssh-manager检查现有镜像实际加载协议，条件允许时独立CPU权重预测验证。运行验证任务会明确产生推理负载，不自动运行真实业务验证集。
5. 核对活动任务和数据保护后在本机启用，记录真实与隔离验证边界。
