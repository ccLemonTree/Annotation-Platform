# 平台界面统一

目标：主平台全部路由与 SmartEye 六个功能页使用相同浅色工作台、字体、蓝色主操作、边框、表单和表格尺寸；保留接口、鉴权、数据和原有任务功能。

假设：保留 Ant Design 和 SmartEye 已有 Tailwind，保留 iframe 隔离。此次不新增业务功能，也不迁移后端。

1. `frontend/src/ui/`：共享主题、设计变量；两个入口均使用同一 Provider。验证：构建双入口、浏览器读取计算样式。
2. 主布局、登录、仪表盘、列表工具栏、标注工作台：统一层级，响应式侧栏/表格，明确导航与可访问名称。验证：所有主路由、弹窗、窄屏无页面水平溢出。
3. SmartEye：移除独立深色品牌侧栏，保留六个入口；用途栏、任务抽屉复用 AntD，已有查询/下载/生成组件共用变量及表单/卡片规范。验证：六页切换、用途选择、任务列表、查询筛选展开、空状态。
4. 验收：TypeScript/Vite 构建、lint、Playwright 实际页面截图与只读交互，记录边界。不会提交真实平台下载、收费生成或修改已有标注。

使用的 ui-skills MCP 规范：ibelick/baseline-ui、ibelick/fixing-accessibility。复用已有 AntD 原语，不引入动画或新组件库。
