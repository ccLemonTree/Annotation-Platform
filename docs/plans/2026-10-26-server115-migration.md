# 115服务器迁移计划

**Goal:** 将运行和开发主目录切换到115服务器，保留现有数据、账号和功能。

**Architecture:** 数据库已位于115，保持原库；代码和本地文件复制到`/ai/chen/code/workspace/数据管理平台`。先复制、校验并构建，再停本地服务，复核数据无变化后启动远端单实例。原目录保留回退副本。

**Tech Stack:** Python 3.12、Node 22、FastAPI、Vite、PostgreSQL、systemd、ssh-manager MCP。

1. 核对目标目录、端口、容量和活动任务；目标父目录已有其他项目，新建独立子目录。
2. 通过ssh-manager MCP传输代码、文件存储、私有配置和SSH桥接依赖；逐文件SHA256检查，重建Linux依赖。
3. 后端使用空闲的18000本机端口，前端3000；复用数据库及JWT/凭据密钥，迁移本地配置路径。
4. 远端构建及隔离测试通过后停本地服务，复核业务表和文件指纹，启动受systemd管理的远端服务。
5. 验证登录态只读API、图片、冻结包、审核筛选、SSH桥接及前端访问；记录远端开发命令和回退方式。未经用户操作不启动训练、模型下发或业务写入。
