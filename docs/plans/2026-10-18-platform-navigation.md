# 平台交互与跳转优化

## 范围与验收

保留钴蓝主题、现有数据规则、审核规则与手动启动训练。只修改前端导航与表单上下文，不改变业务数据。

1. 只读走查 14 个主要页面，记录入口与断点。证据：`output/navigation-live-audit.txt`（写请求为 0）。
2. 统一项目内图片、准备、标注、审核、导出训练入口。准备使用独立路由，复用已有切图/描述/索引及队列组件；审核页专注审核。
3. 顶部搜索支持按任务找功能，各功能提供关联入口；旧地址继续兼容。项目进入训练时预选项目、数据来源和适用训练器，验证表单预选检测项目。
4. 验证：构建、lint、浏览器项目全流程、深链接和浏览器返回、未保存修改保护、普通用户入口和手机宽度；真实页面只读复核。

## 走查发现与处理

| 问题 | 调整 |
| --- | --- |
| 项目图片、准备、标注、审核、导出分散；返回名称混用 | 项目页共享任务导航，统一名称 |
| 切图/批量描述/索引依赖审核页内部折叠区 | 独立“标注准备”页，直接展示准备操作与任务队列 |
| 检索模式切换后离开即丢失，单图下一张丢失审核来源 | 模式与来源保留在 URL；返回恢复审核筛选 |
| 标注完成后看不到导出或平台训练入口 | 独立“导出与训练”页，复用导出与冻结功能 |
| 创建训练需再次选择项目；预标注不识别项目链接 | 跨页面携带项目参数，不自动保存或启动 |
| GPU/模型/训练/验证页面彼此孤立 | 关联功能快捷入口，训练详情链接权重验证与对应服务器 |
| 多个菜单难以定位，旧描述历史页标题错误 | 顶部按名称/任务搜索，修复标题与所属菜单 |

不新增工作流引擎、不改训练执行或删除行为，不对真实标注执行审核或生成任务。
