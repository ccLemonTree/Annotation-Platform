# 切图连续显示与验证集生命周期

1. 先用隔离API与浏览器延迟图片响应复现：切图时外层路由卸载工作台、内层清空图片；验证集缺少删除与最新标注更新入口。
2. 保持检测工作台与旧画布至下一张解码成功，图片/框/尺寸一起提交；路由和显示图片不一致时禁用编辑、保存、审核、预测应用与切图快捷键，失败保留旧画布；object URL在替换或卸载时释放。
3. 验证集是真值快照。“更新标注”在同一批图片范围读取最新已审核通过的版本，生成新验证集，原验证集和历史任务不变。冻结包更新不继承val/test独立性声明。删除集需管理员确认，删除关联历史任务/逐图结果，保留项目原图/标注/权重；有活动任务/远端占用则拒绝。
4. 验证：最新标注及类别、历史稳定、未审核拒绝、删除权限/租户隔离/活动任务保护；浏览器延迟与失败图片、不同分辨率、更新/删除确认及错误；旧验证/标注回归、前端构建。真实记录不自动更新或删除。
