# 标注与审核按项目组织

目标：标注与审核先展示标注项目，再进入单个项目；避免跨项目混合和长ID挤占主要布局。

1. 复现原列表缺少项目上下文及长ID/操作拥挤问题，先写浏览器用例并确认失败。
2. 复用getProjects/getProject和getAnnotations的project_id过滤，项目概览分页，详情以图片预览/名称/框数/版本/状态为主。只读取当前标注页对应的资产详情，不加载项目全部图片。
3. 移除页面的JSON审核弹窗及未看图片的快捷通过按钮；审核统一在现有画框工作台完成，主审核API与工作台功能保留。工作台返回标注项目列表的原项目和筛选页；从项目图片进入时仍返回项目图片。
4. URL保留项目、审核状态和页码，测试刷新/后退、切图返回、空项目、读取失败恢复和窄屏。写入拦截，不修改真实标注/冻结包。
5. 双入口构建、编辑器与自动保存/导航/UI回归；只读比较业务记录和原图/冻结包哈希，更新操作说明和验收记录。
