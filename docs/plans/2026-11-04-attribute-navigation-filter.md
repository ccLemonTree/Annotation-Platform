# 属性标注工作台按属性筛选

**目标：** 在属性标注工作台选择属性、精确值或判断状态，所有切图、跳转及连续审核均留在筛选范围。

**方案：** 复用 `services.object_attributes.attribute_query` 的最新标注、空值、缺失与目标范围语义。资产列表、全选和 neighbors 使用同一属性子查询，延续既有项目权限、图片集、分类标签、审核状态及裁剪范围交集。不增加数据迁移或索引方案。

前端复用既有 URL 查询参数 `attribute_key`、`attribute_value`、`attribute_state`。可搜索枚举建议，任意文本值按回车/筛选按钮显式应用，避免打字时反复跳图。切换属性清空原值；切换未知/缺失状态清空不兼容的具体值。未保存时禁用筛选；空结果或读取失败保留当前图片与条件。保存或审核导致不再匹配时仍按当前锚点寻找范围内相邻图片。

**验证顺序：**

1. 新增 SQLite 隔离 API 测试，先确认旧接口忽略属性参数导致失败；覆盖最新版本、精确值、未知/缺失、分页/全选/相邻、审核条件交集、范围与参数校验。
2. 将公共资产查询接入现有属性查询；通过测试及原导航、属性结果回归。
3. 增加工作台控件和 URL/请求参数传递，隔离浏览器验证筛选、空结果、改标后离开范围、序号跳转、连续审核以及未保存保护；运行前端构建。
4. 通过 ssh-manager 按当前服务器基线合并本次差异，完成候选验证。重启后端前检查实际活动任务，等待既有批次完成后发布；验证健康、查询协议和业务数据一致性，保留验收证据。
