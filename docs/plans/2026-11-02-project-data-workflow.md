# 项目、场景与数据复用改造

## 用户确认

- 拉取图片按设备名称判定场景；同一设备后续图片继承结果，不逐图推理。
- 按标签和场景复用已有数据，可选择复制来源项目已审核标注；原图共享，标注复制后各项目独立。
- 本次仍暂不发布，保留待部署结果，不更新或重启115正式服务。
- 项目列表直接上传、预标注与AI审核，在弹窗/抽屉内创建任务、查看进度和最终审核，不强制跳页。
- 重复图片复用同一原图；带入已有标注仅保留目标项目标签匹配内容，全部不匹配不能变成负样本。
- 数据拉取页也可直接新建项目并选中，从当前项目打开预标注与AI审核，不丢失查询结果。
- 登录有效期改为24小时；过期认证跳转整个页面，登录成功返回原业务入口及项目参数，不能在数据拉取内嵌窗口里打开主系统。

## 实施决定

1. 补齐全部实际拉图路径的设备来源，使用平台与设备ID识别设备，名称与场景配置作为分类版本；新增/改名才排队，人工结果优先。设备来源图跳过视觉分类，设备结果传播原图；相同字节多来源保留来源并合并场景。
2. 管理员待审抽为独立入口，接口补齐项目名、图片名与任务类型，工作台保留来源回跳；普通标注审核和AI转人工审核保持各自状态规则。
3. 项目是主要入口，沿用现有项目流程组件贯穿批量处理、待审、分析、数据准备和交付；共享图库保留为跨项目复用数据源。
4. 复用选图增加来源项目、最新标注标签、审核状态与场景组合。列表和全选共用过滤条件；可选复制源项目最新已审核标注，目标已有标注保留，按目标项目标签过滤带入内容，全部不匹配时不创建标注。复制记录来源版本/审核证据，标签范围变化后待审核，不伪造本项目人工审核。
5. 项目直接上传按上传回执的精确图片ID关联，不能把整个图片集或按首次batch_id误当本次图片；复用已存在原图也能关联，不移动或复制原图。
6. 模型列表分别显示启用与最近连接状态；复用现有连接检测，按配置版本保存在线/离线、原因和时间，编辑后失效，迟到检测不覆盖新配置。
7. 分析页四处大ID集合改为SQL子查询，保留既有统计定义。已确认asyncpg参数上限是正式报错根因，非缺表或数据库断连。
8. 项目列表复用现有上传弹窗与批量任务页面，固定当前项目；上传关闭时保留组件继续处理并禁止切换上传目标，批量任务与管理员预览嵌在抽屉中，切换项目重建任务上下文。
9. 数据拉取在检测/台账顶栏及设备抓图页提供新建项目和预标注入口，父页面验证同源及子窗口来源后按项目ID重新读取项目并打开现有任务抽屉。新建项目不修改既有定时计划。
10. Axios与SmartEye fetch统一处理过期认证，登录跳转顶层并保留安全内部返回路径；Vite区分/smarteye文档入口与同名静态目录。JWT默认及示例配置改为86400秒，登录响应和签名使用同一配置；正式.env仍需在发布时改JWT_EXPIRATION=86400，不改密钥，已有token不能延寿。
