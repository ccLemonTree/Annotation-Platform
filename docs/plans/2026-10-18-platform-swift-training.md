# 平台标注数据接入 Swift / WeMM 训练

范围：训练页面、冻结导出 API、训练配置校验、远端解包与 JSONL 图片路径、相关测试。复用 ExportSnapshot 和既有 SHA256 传输，不改数据库、不自动启动训练、不改已有服务器路径或检测训练行为。

1. 添加失败测试：项目标注冻结为 SFT/四种 embedding 格式，租户隔离、空数据/格式不匹配/冲突拒绝；冻结版本可创建和编辑待启动训练。
2. 最小接入：平台数据选项、项目/来源和固定版本选择；冻结成功后自动选择版本。后端复用现有图片包构建与存储，训练器按 task_type/loss_type 匹配版本。
3. 远端解包验证每张图片哈希，将 train.jsonl 的独立图片字段改为容器内绝对路径，不依赖工作目录；保留输入 ZIP。外部验证 JSONL 沿用原配置，不自动划分训练/验证数据。
4. 验收：隔离 API 生命周期及失败测试、生成训练命令与本机模拟解包、真实浏览器拦截 API 验证创建/编辑/错误/移动端，构建和 lint；本机接口只读检查部署版本，不启动或停止远端训练。

数据质量：同一文本或图片 anchor 对同一图片存在正负冲突时拒绝导出/冻结，明确提示统一历史判定，不自行选择用户的最终标注。
