# 项目类别同步与切图自动保存

1. 类别修改必须有明确旧→新映射，不根据位置猜测。新增label_renames和base_label_schema请求字段；页面列出项目配置及当前标注使用的类别，包含既有“人”→配置“person”的不一致。已有框类别删除但未映射时拒绝更新，新增/排序不改框。
2. 同一事务锁图片再锁项目，校验旧配置、防止旧标注在改名后写入。映射当前最新标注，复用save_annotation生成新版本及待审核状态；保存历史和冻结包不改写，统计保持一致。
3. 所有工作台内部图片路由切换由现有路由阻止器先保存；无修改不写入，保存失败/409/未确认负样本留在原图，按钮和快捷键一致，单次保存防重复。
4. 验证：映射/移除/排序/交换/陈旧配置及旧版本保存、冻结保护；浏览器模拟改名和切图保存成功/失败/冲突。部署主后端后对test-img明确的“人”→“person”不一致进行有备份的版本同步，不修改几何和冻结包。
