# 模型预览标签与无置信度模型

假设：当前 `/detect/grounding` 接口的 VLX-Seek、GroundingPI 不提供可用检测置信度，也不执行 NMS；其余接口沿用既有契约。标签只覆盖本次预览，不修改模型管理配置。

1. 增加失败回归：预览标签传到冻结推理配置；占位分数不参与过滤或返回为真实置信度；普通检测模型保持原行为。
2. 复用现有 labels 请求，预览增加标签输入；按接口契约关闭无效参数，后台也跳过这些参数；无置信度结果显示“未提供”。
3. 验证后端专项、前端构建、真实浏览器切换与请求；实际服务调用确认标签与高阈值不误删结果。更新适配器时只重启本次部署的两个容器。

限制：不新增通用能力配置或数据库迁移；无分数结果不用于计算依赖置信度的验证指标。
