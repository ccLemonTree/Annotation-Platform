# 检测工作台审核状态筛选

**Goal:** 工作台按最新标注的待审核/已通过/已驳回筛选，与标签取交集，切图、序号跳转、刷新和返回审核页保持范围。

**Architecture:** 扩展既有asset_conditions及列表/全选/邻居接口；复用URL review_status，不把资产annotation_status当作审核状态。无状态参数保持兼容。当前图片审核后离开筛选时保留画面，邻居仍在筛选集合中并明确提示；不自动切图。

1. 先写失败测试：最新版本、审核与标签交集、分页/全选/邻居一致、当前图不再匹配及空队列、范围/权限和参数验证。
2. 后端筛选统一处理，响应声明支持审核筛选；前端拒绝旧后端忽略筛选的结果。
3. 工作台增加状态控件，统一标签/状态切换，保持URL和序号跳转；保存/审核后重新读取队列。
4. 隔离浏览器验证入口继承、交集、刷新、切图/跳转、空结果及审核后队列；相关后端回归、构建、只读真实接口验证。业务审核及标注数据不自动修改。
