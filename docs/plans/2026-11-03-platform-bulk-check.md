# 平台一键检测与搜索框修正

**目标：** 搜索框恢复标准控件样式；管理员一键检测所有平台，能查看进度与停止。

**范围与假设：** 全部指当前主租户可见、未删除的平台，包含停用项，不受搜索或分页影响。只验证连接及登录，不查询全部设备、不拉图、不分类，不启用定时探测。缺少地址、账号或密码时标记未配置。复用既有任务、鉴权与登录流程，无数据库迁移和新依赖。

1. 用隔离测试复现缺少批量检测端点，以及搜索框内层原生样式污染。验证权限、全部范围、异常隔离、凭据不外泄、并发和取消。
2. 管理服务提取共用连接检测；新增 `platform-check` 后台任务，限制一批、最多两个登录请求并行，保存结果和数量，刷新后可读取最近任务。
3. 修正旧样式对 Ant Design 输入框的覆盖；平台页增加按钮、进度、结果摘要和停止入口。
4. 运行本地隔离后端、前端构建与模拟浏览器验证；检查115活动业务，按哈希备份并更新，只读验收；不启动真实全平台检测。

取消后不检测后续平台，当前平台的登录流程（含已有重试）需等待结束或超时；返回后不写入迟到结果。服务重启沿用既有任务中断语义，不自动重跑。

## 发布选择

用户明确选择“保留分类，批量检测暂存待发布”。搜索框样式单独热更新；其余五个文件保持正式版本，完整六文件包及部署脚本已在115隔离目录暂存。本次不重启、不停止分类、不执行真实全平台检测。
