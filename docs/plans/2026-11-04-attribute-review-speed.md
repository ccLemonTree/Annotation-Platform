# 目标属性人工审核效率优化

**目标：** 减少单图属性审核的滚动、下拉选择及保存/通过/切图操作，保持原权限、版本校验、概率证据和审核规则。

**方案：** 复用 Ant Design 和现有标注 API。属性编辑器采用紧凑行，直接点选最多三个最高概率候选（无概率且不超过三个选项时直接显示选项），完整枚举仍可搜索选择。说明和可选原因折叠；无法判断原因始终显示。操作区置于独立滚动区之外，保持可见；新增顺序执行的保存、人工通过、刷新筛选后下一张操作。

**约束：** 不按概率自动审核，不批量通过，不更改模型调用或已有数据。保存失败不审核，审核失败不切图，取下一张失败保留已成功的保存/审核结果。连续点击受现有写入锁保护；切图等待草稿状态提交后才执行，避免未保存拦截误报。无下一张时停留并提示。

**影响范围：** `AttributeEditor.tsx`（仅一个调用方）、`ImageAnnotationWorkspace.tsx`/CSS、对应隔离 Playwright 脚本和操作说明。后端及数据库协议不变。

**步骤及验证：**

1. 写隔离浏览器用例并确认旧界面失败：候选直接点选、7属性布局、操作可见、概率保留、未知原因可编辑。
2. 最小实现编辑器和连续审核操作，验证筛选参数、失败停留、重试、重复点击、最后一张及键盘 R 行为。
3. 运行原 JEV、属性工作台、筛选与属性编辑回归，前端构建及截图检查；记录实际高度及步骤变化，不宣称未经测量的审核耗时。
4. 通过 ssh-manager 核对 115 源码差异，备份后只更新本次前端差异；使用现有 Vite 热更新，不重启后端、不打断正在运行的推理任务。核对源码、页面及 API 健康并记录验收。
