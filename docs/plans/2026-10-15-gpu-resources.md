# GPU资源页面实施计划

**目标：** 查看绍兴A100服务器真实GPU指标及计算进程，限管理员，只读。

**方案：** FastAPI通过本机配置的ssh-manager MCP stdio入口调用固定采集命令。沿用ssh-manager的连接与凭据，不新增SSH库、不向浏览器暴露密码或任意命令入口。15秒共享缓存限制重复采集，前端30秒可选自动刷新。

**技术栈：** 现有Python/FastAPI、Node及ssh-manager自带MCP SDK、React/Ant Design。无需数据库迁移。

1. 定向测试先覆盖CSV解析、未知值、MIG、跨卡进程、异常和管理员权限；确认失败后实现后端采集、缓存、固定MCP桥接。
2. 新建GPU页面、API封装及导航；验证载入、刷新、未知值、失败保留旧数据、权限和窄屏。
3. 通过ssh-manager核对绍兴a100，再经平台API及真实页面联调；运行相关回归、构建并更新TODO与交接。

**验收边界：** GPU UUID为物理关联依据，显示剩余显存而非可调度配额，计算进程不代表全部图形/MIG工作负载。仅单机监控，不部署远程代理，不调整在线服务，不终止进程，不保存历史或执行训练。
