# 服务器管理接口

页面：`/gpu-servers`，GPU资源页面也提供入口。接口前缀 `/api/gpu-resources/servers`，仅管理员可用，使用 `Authorization: Bearer $TOKEN`；TOKEN获取方式见[模型仓库接口](模型仓库接口.md)。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | 前缀本身 | 当前租户服务器列表，含只读默认连接 |
| POST | 前缀本身 | 表单新增一个连接 |
| POST | `/import` | JSON整批新增连接 |
| PATCH | `/{id}` | 更新自建连接 |
| DELETE | `/{id}` | 删除自建连接及保存的密码 |

批量文件是UTF-8 JSON，示例（替换密码后使用）：

```json
{"servers":[{"name":"训练服务器","host":"192.0.2.10","port":22,"username":"root","password":"实际密码","enabled":true}]}
```

必填字段为 `name`、`host`、`password`；`host`为IPv4或IPv6地址。可选字段默认值：`port=22`、`username=root`、`enabled=true`。页面可下载模板，支持1至200条、最大1MiB的JSON文件。

## 跳板机

表单可启用“通过跳板机连接”；JSON新增和批量导入使用可选的 `jump` 对象：

```json
{"servers":[{"name":"内网训练服务器","host":"10.0.0.10","password":"目标服务器密码","jump":{"host":"192.0.2.1","port":22,"username":"root","password":"跳板机密码"}}]}
```

支持一个跳板机，目标和跳板均使用SSH密码认证；跳板机的 `host`、`password` 必填，`port`、`username` 默认22、root。不使用跳板时省略 `jump` 或设为 `null`。GPU资源、训练、权重验证及SSH调试共用该连接，目标机只需能被跳板访问。

编辑时不传 `jump` 保留已有跳板；传 `jump:null` 移除跳板，后续直连。传 `jump` 对象时填写完整的跳板地址和账号，密码留空保留原值；新增或改变跳板IP、端口、用户名必须填写跳板机密码。列表只返回 `jump.host/port/username/has_password`，不回显两端密码。跳板密码与目标密码分别加密保存，临时SSH配置仅传入子进程，不写到命令参数或日志。

## 提交和结果

```bash
BASE=http://192.168.1.115:3000
curl --fail-with-body "$BASE/api/gpu-resources/servers/import" \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  --data-binary @servers.json
```

成功返回201和 `{"imported":数量,"items":[连接摘要]}`。批内或当前租户已有相同目标IP、端口、用户名和跳板地址、端口、用户名时返回409；不同跳板后的相同内网地址可分别保存。任一字段无效返回422；总数量超过每租户200台返回409。整批失败不保存任何连接，也不隐式覆盖现有配置。不同租户独立管理。

密码加密保存，列表和结果只返回 `has_password`，不会返回密码。JSON原文件包含明文密码，请妥善保管。更新时留空密码保留原密码，改变IP/端口/用户名必须重填密码。存在活动训练或验证时不能更新或删除对应连接。默认 `ssh-manager` 连接在此只读。保存或导入连接不会启动采集或SSH测试。
