# 训练效果分析与历史模型对比

入口：模型训练列表的“效果分析与对比”，或训练详情中的同名标签。先点击“读取指标并对比”，再选择大模型并生成报告。单次最多对比3个早于当前任务、状态为已完成的任务；候选列表支持加载更多。没有历史任务时可以单独分析。

支持平台所有训练器，按已保存的数值指标读取。YOLO 使用 results.csv；RF-DETR 使用 metrics.csv 或 COCO JSON 日志；Swift SFT / WeMM 使用 trainer_state.json 的 log_history、logging.jsonl 与结果 JSON；DINOv3 / LightlyTrain 使用 metrics.jsonl / CSV。不存在、格式不支持或读取失败时明确提示，不加载权重推测成绩。LightlyTrain JSONL 格式依据[官方源码](https://github.com/lightly-ai/lightly-train/blob/main/src/lightly_train/_loggers/jsonl.py)。只存在 TensorBoard 二进制日志时本期不解析。

每项指标提供首次、最后有效值、各自最佳值及其 epoch/step，并保留最多80个曲线采样点。损失/error越低越好，mAP/AP、precision、recall、F1、相关系数等越高越好，未知方向只展示参考值。不同文件的指标不自动合并；EMA与regular分别统计。best可能来自不同检查点，last不等于最终权重的独立评估成绩。

已完成任务的产物目录不可读或指标缺失时，优先使用该租户、该任务最近一份已保存分析报告中的原始指标快照。保留当时的类别顺序、数据来源、评测参数和文件证据，并标注报告ID、保存时间及“非本次服务器读取”；不会将快照伪装成当前目录里的文件。没有可用快照时仍明确提示缺失。指标快照不能恢复已删除的权重。

历史对比只计算同一相对文件路径、同名指标的原始差值（当前减历史），不把不同IoU、EMA、损失函数强行合并。页面和大模型均获得数据快照、类别顺序、训练器、验证配置差异提示。服务器相同路径不能证明数据相同；即使平台快照相同，仍需核对评测版本、阈值和检查点。跨训练器可同时分析，但条件不一致不可直接排名。

大模型复用模型管理中已启用的 OpenAI 对话模型，不新增服务配置。模型管理可以编辑默认“训练效果分析提示词”，每次分析也可单独编辑；报告保存该次提示词、模型名称/版本、文件SHA256与指标证据。模型只接收每个任务最多16项核心指标摘要和相关差值；完整指标保留在页面。不给大模型发送训练环境变量、SSH连接密码、API密钥或原始控制台日志。生成失败不保存假报告，页面已读取的指标保留。

训练分析请求遇到上游HTTP 502/503/504时，等待0.5秒后最多重试一次；鉴权、参数、格式错误不重试。页面错误提示区分上游HTTP状态、鉴权、服务路径、网络连接及请求超时，不回显上游响应正文或凭据。报告只在有效结果返回后保存一次。

| 方法 | 路径（前缀 /api/training） | 用途 |
|---|---|---|
| GET | /runs/{id}/comparison-candidates?page=1&page_size=20 | 当前租户的更早已完成任务 |
| POST | /runs/{id}/analysis/evidence | 读取当前及历史任务指标，body: `{"compare_ids":[]}` |
| POST | /runs/{id}/analysis | 管理员调用大模型并保存，body: `{"compare_ids":[],"model_id":"UUID","prompt":"可选，省略使用模型默认提示词"}` |
| GET | /runs/{id}/analysis | 最近10份报告的轻量摘要 |
| GET | /runs/{id}/analysis/{report_id} | 报告与证据快照详情 |

所有入口按租户和任务鉴权。只读接口不需要管理员权限；生成报告需要管理员。禁止当前任务与自身对比、重复任务、未来任务或未完成历史任务。SSH只使用现有ssh-manager MCP通道执行固定只读采集器，不启动训练、不分配GPU、不停止容器、不写远端产物。

读取上限：目录深度5层、最多200个目录、12个指标文件；每文件4MiB、合计8MiB、每文件50000条记录、全任务80项指标。超过上限或正在变化的文件明确提示。Swift多份累计trainer_state只选最近更新的一份；不把不同来源日志拼成同一曲线。仅解析白名单指标文件，排除符号链接及权重。

部署执行 `alembic upgrade head` 到023，只新增training_analyses表。报告随当前任务记录删除，服务器产物保留；已保存报告里的历史模型证据不依赖旧任务继续存在。迁移禁止自动降级删除报告。
