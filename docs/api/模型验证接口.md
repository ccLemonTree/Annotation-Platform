# 模型验证接口

前缀 `/api/validation`，统一使用主平台Bearer认证。同租户用户可读取；创建、取消、重试仅管理员。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET / POST | `/sets` | 分页列出 / 保存验证真值快照 |
| GET | `/sets/{set_id}` | 验证集名称、类别、来源、数量；不暴露存储路径 |
| GET / POST | `/runs` | 分页列出 / 创建验证任务 |
| GET | `/runs/{run_id}` | 任务参数、权重/模型版本、指标和覆盖率；只读 |
| POST | `/runs/{run_id}/cancel` | 取消未完成图片，保留成功结果；也可再次确认远端停止 |
| POST | `/runs/{run_id}/retry` | 重试失败/取消项，拒绝已变更权重/镜像或模型修订 |
| GET | `/runs/{run_id}/items` | 分页逐图真值、预测、错误和TP/FP/FN |
| GET | `/runs/{run_id}/items/{item_id}/image` | 认证读取经哈希和尺寸核对的原图 |
| GET | `/runs/{run_id}/report` | 下载JSON报告，包含类别、权重溯源和逐图结果；不包含连接凭据 |

创建验证集示例：

```json
{"name":"人检测验证集-v1","project_id":"项目UUID"}
```

项目来源保存当前已确认的最新标注：人工审核通过，或从图库带入管理员信任的YOLO标注。可增加 `asset_ids` 明确选择，必须全部属于项目并符合确认条件；不默默排除无效所选图片。`source.imported_annotation_count` 记录导入来源数量，`review_policy` 为manual_or_admin_trusted_import；含导入来源时不声称全部逐图人工审核。

冻结来源增加 `snapshot_id` 和 `split`（`val` 或 `test`），固定历史版本和清单类别；缺少历史人工审核证据时400。

直接验证训练权重（当前页面默认）：

```json
{
  "set_id":"验证集UUID",
  "name":"RF-DETR权重验证",
  "checkpoint":{
    "server_id":"default",
    "kind":"rfdetr_medium",
    "weight_path":"/ai/chen/train/rf-detr/outputs/rfdetr_medium/checkpoint_best_total.pth",
    "image":"aisfh5.com:9091/ai/jashan_train:yolo-rfdetr",
    "device":"cpu",
    "class_names":["fire","smoke"]
  },
  "config":{
    "inference_confidence":0.001,
    "confidence":0.25,
    "match_iou":0.5,
    "nms_iou":0.45,
    "labels":[],
    "label_mapping":{}
  }
}
```

示例路径需存在于所选服务器，不是自动上传。`server_id` 为 `default` 或已启用服务器UUID。`kind` 支持 `yolo26/rfdetr_medium/rfdetr_2xlarge`；`device` 为 `cpu` 或读取到的物理GPU UUID。RF-DETR的 `class_names` 必须按训练编号从0排列，YOLO留空时从权重读取。2XLarge另需 `accept_platform_model_license:true`。

选择平台训练产物时增加 `checkpoint.training_run_id`：只允许已结束任务、原服务器和模型类型，权重必须位于原输出子目录，镜像由后端沿用原任务。创建时读取权重SHA256和镜像digest，固定到任务；不自动拉取镜像、下载权重或启动训练。GPU预留与训练互斥，CPU不占GPU。

旧调用仍可用 `model_id:"检测服务UUID"` 替代 `checkpoint`；两者必须且只能提供一个。旧任务与指标接口兼容。

权重任务响应的 `model` 增加 `source:"checkpoint"`、`weight_path`、`weight_sha256`、`image_digest`、`kind`、`device`，`id`为权重哈希。`remote_active:true` 表示尚未确认独立容器停止；即使任务已取消/失败，GPU预留仍保留，须再次调用cancel成功后才能retry。重试仅针对失败/取消项，固定文件或镜像变化时409，需新建任务。

分页统一 `page`、`page_size`；集合支持 `project_id`，任务支持 `set_id`。逐图过滤 `error_type=false_positive|false_negative|class_confusion|failed|correct`。

`metrics.coverage` 包含 `total/succeeded/failed/pending/canceled/complete`。成功样本缺失时比率可为null；部分结果不能当作完整验证。任务和条目状态为 `pending/running/completed/failed/canceled`。

401未登录，403无管理员权限，404不存在或不属于当前租户，400真值/模型/来源条件不满足，409资源占用、版本冲突或冻结图片变化，422参数无效；远端通信/执行失败可返回502/503。逐图错误脱敏，报告仅公开指定权重路径及哈希，不含SSH连接信息、服务鉴权或环境变量。

操作及指标口径见[验证集说明](../development/模型验证集.md)。
