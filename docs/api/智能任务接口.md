# 智能任务与分析接口

均使用现有Bearer认证与租户范围检查。模型密钥只引用服务器环境变量，不保存在任务参数或返回体中。

| 方法与路径 | 用途与权限 |
|---|---|
| POST /api/automation/jobs | 管理员创建项目预标注或AI审核任务 |
| GET /api/automation/jobs | 分页查看任务，可按project_id筛选 |
| GET /api/automation/jobs/{id} | 单任务进度 |
| GET /api/automation/jobs/{id}/items | 分页明细，可按status筛选 |
| POST /api/automation/jobs/{id}/cancel | 管理员取消未完成项；阻止迟到写入 |
| POST /api/automation/jobs/{id}/retry | 管理员重试失败/取消项；模型变更需新建任务 |
| GET /api/automation/review-queue | 管理员待审队列，支持项目及分页 |
| POST /api/automation/items/{id}/resolve | 管理员approved/comment；批准须版本一致，驳回可丢弃过期候选 |
| POST /api/image-semantics/jobs | 图片/图片集生成描述与向量任务 |
| GET /api/image-semantics/jobs | 分页批次，返回当前页列表 |
| GET /api/image-semantics/jobs/{id} | 批次进度及分页明细 |
| POST /api/image-semantics/jobs/{id}/cancel | 取消全部未完成项，或body.item_ids指定项 |
| POST /api/image-semantics/jobs/{id}/retry | 重试失败/取消项，或body.item_ids指定项 |
| POST /api/image-semantics/search | 文本或库内图片的余弦TopK检索 |
| GET /api/analytics | 项目、日期范围的质量流程/人工效率分析 |
| POST /api/analytics/activity | 当前用户工作台短区间计时，session_id+sequence去重 |

预标注请求示意（UUID使用实际项目和模型ID）：

```json
{
  "project_id": "00000000-0000-4000-8000-000000000001",
  "kind": "preannotate",
  "detector_id": "00000000-0000-4000-8000-000000000002",
  "reviewer_id": "00000000-0000-4000-8000-000000000003",
  "config": {
    "confidence": 0.25,
    "iou": 0.45,
    "auto_approve_confidence": 0.9,
    "crop_expansion": 0.2,
    "auto_review": true,
    "labels": [],
    "label_mapping": {},
    "prompt": ""
  }
}
```

`kind=review` 不需要detector_id；asset_ids可选，不填按项目中符合条件的图片。预标注只入队未标注图，review只入队已有标注。模型/项目/内容/版本变化造成的旧结果被跳过，不自动覆盖。

图像语义创建需要collection_id或image_ids，以及caption_model_id/embedding_model_id至少一个。检索必须提供embedding_model_id与text或image_id二选一，top_k=1–100；当前维度固定实际WEMM的2048。向量完整保存在服务器，不向浏览器发送向量数组。

Qwen核心提示词随模型配置的`chat_prompts:{caption,review}`保存，默认值读取GET `/api/model-services/prompt-defaults`，修改权限沿用管理员。语义创建的prompt省略/空字符串时使用模型caption核心指令，非空覆盖该批描述（最多2000字符）；automation.config.prompt是追加审核要求，不覆盖review核心指令。模型快照包含核心提示词，旧快照缺少此字段时按默认值兼容读取。

分析start/end要求带时区，使用UTC半开区间[start,end)。计时提供project_id、asset_id、session_id、sequence、activity（annotation/review）和带时区started_at/ended_at。超时、未来或非法范围422，跨租户404，非管理员自动任务写入403，过期批准/配置变化409；推理失败保留原图及可追溯状态。
