```python
async def test_smarteye_end_to_end():
    """测试：创建任务 → 下载 → 查看结果 → 导入项目"""
    
    # 1. 创建任务
    task = await create_task(
        task_name="测试任务",
        platform_id=platform_id,
        query_params={
            "startTime": "2024-01-01 00:00:00",
            "endTime": "2024-01-02 00:00:00"
        }
    )
    assert task.status == "pending"
    
    # 2. 执行任务
    await execute_task(task.id)
    task = await get_task(task.id)
    assert task.status == "completed"
    assert task.downloaded_count > 0
    
    # 3. 查询下载记录
    downloads = await list_downloads(task.id)
    assert len(downloads) == task.downloaded_count
    
    # 4. 导入到标注项目
    result = await import_from_smarteye(
        project_id=project_id,
        smarteye_task_id=task.id
    )
    assert result["imported_count"] == task.downloaded_count
    
    # 5. 验证Asset记录
    assets = await list_assets(project_id)
    assert len(assets) == result["imported_count"]
    assert assets[0].source_type == "smarteye"
```

#### 7. 技术决策记录（ADR）

**为什么需要**：
- 记录重要技术选型的原因
- 帮助新成员理解历史决策
- 避免重复讨论已解决的问题

**示例**：

```markdown
# ADR-001: 选择PostgreSQL作为主数据库

## 状态
已接受

## 背景
需要选择一个数据库存储SmartEye任务、标注数据、训练记录等。

## 决策
选择PostgreSQL 14作为主数据库。

## 理由

### 优势
1. **JSONB支持**：query_params等动态字段存储为JSONB
2. **事务完整性**：ACID保证数据一致性
3. **扩展性强**：支持PostGIS、全文搜索等扩展
4. **成熟稳定**：大量生产案例
5. **开源免费**：无授权成本

### 备选方案对比
```
