## 💡 使用技巧

### 在VSCode中快速跳转
1. 按 `Ctrl+P` 打开文件搜索
2. 输入文件名（例如：`api_guide`）
3. 按回车打开文件

### 在GitHub中搜索文档
1. 按 `/` 打开搜索
2. 输入关键词
3. 筛选只在文档中搜索

### 导出为PDF
```bash
# 使用pandoc转换
pandoc README.md -o README.pdf

# 或使用markdown-pdf
npm install -g markdown-pdf
markdown-pdf README.md
```
