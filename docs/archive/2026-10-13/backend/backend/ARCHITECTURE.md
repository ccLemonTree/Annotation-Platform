## 核心模块说明

### 1. API层 (FastAPI)

#### 认证授权模块 (`api/auth_routes.py`)
- 用户注册、登录
- Token生成和验证
- 权限检查

#### 项目管理模块 (`api/project_routes.py`)
- 项目CRUD操作
- 项目统计信息
- 项目配置管理

#### 资产管理模块 (`api/asset_routes.py`)
- 文件上传（单个/批量）
- 资产列表和详情
- 资产删除

#### 标注管理模块 (`api/annotation_routes.py`)
- 标注CRUD操作
- 标注审核
- 标注历史

#### SmartEye集成模块 (`api/smarteye_routes.py`)
- 模型列表和信息
- 模型推理
- 训练任务管理

#### 训练管理模块 (`api/training_routes.py`)
- 训练任务创建
- 训练进度监控
- 模型评估

### 2. 业务逻辑层 (Services)

#### 认证服务 (`services/auth/`)
- JWT Token管理
- 密码哈希验证
- 权限控制

#### 存储服务 (`services/storage/`)
- **本地存储** (`local.py`): 本地文件系统存储
- **EOS存储** (`eos.py`): 企业对象存储集成
- **抽象接口** (`base.py`): 统一的存储接口

#### SmartEye服务 (`services/smarteye/`)
- **平台管理器** (`platform_manager.py`): SmartEye平台集成
- **下载服务** (`download_service.py`): 模型下载和管理

### 3. 数据模型层 (Models)

#### 基础模型 (`models/base.py`)
```python
- id: 主键
- created_at: 创建时间
- updated_at: 更新时间
- deleted_at: 软删除时间
```

#### 租户模型 (`models/tenant.py`)
```python
- name: 租户名称
- domain: 租户域名
- settings: 租户配置
- is_active: 是否激活
```

#### 用户模型 (`models/user.py`)
```python
- tenant_id: 所属租户
- username: 用户名
- email: 邮箱

- full_name: 全名
```

#### 项目模型 (`models/project.py`)

```python
- tenant_id: 所属租户

- task_type: 任务类型
```

### 4. 数据验证层 (Schemas)

使用Pydantic进行数据验证：

#### 通用Schema (`schemas/common.py`)
- PaginationParams: 分页参数
- PaginatedResponse: 分页响应
- SuccessResponse: 成功响应
- ErrorResponse: 错误响应

#### 各模块Schema
- 创建Schema: 创建资源时的输入验证
- 更新Schema: 更新资源时的输入验证
- 响应Schema: API响应的数据格式

## 数据流图

### 用户注册/登录流程

```
客户端 → POST /api/auth/register
         ↓
      验证输入数据 (Pydantic)
         ↓
      密码哈希 (bcrypt)
         ↓
      创建用户记录 (SQLAlchemy)
         ↓
      返回用户信息

客户端 → POST /api/auth/login
         ↓
      查询用户 (username)
         ↓
      验证密码 (bcrypt)
         ↓
      生成JWT Token
         ↓
      返回Token和用户信息
```

### 文件上传流程

```
客户端 → POST /api/assets/upload
         ↓
      验证用户权限 (JWT)
         ↓
      验证文件类型和大小
         ↓
      计算文件哈希 (SHA256)
         ↓
      保存文件 (存储服务)
         ↓
      提取图像信息 (PIL)
         ↓
      创建资产记录 (数据库)
         ↓
      返回资产信息
```

### 标注审核流程

```
客户端 → POST /api/annotations/{id}/review
         ↓
      验证审核权限
         ↓
      获取标注数据
         ↓
      执行自动审核 (可选)
         ↓
      更新审核状态
         ↓
      记录审核历史
         ↓
      发送通知 (可选)
         ↓
      返回审核结果
```

### SmartEye训练流程

```
客户端 → POST /api/training/start
         ↓
      验证训练参数
         ↓
      准备训练数据
         ↓
      下载模型 (SmartEye)
         ↓
      提交训练任务
         ↓
      监控训练进度
         ↓
      保存训练结果
         ↓
      更新模型记录
         ↓
      返回训练状态
```

## 安全架构

### 认证机制

```
1. 用户登录
   ↓
2. 生成JWT Token (access_token + refresh_token)
   ↓
3. 客户端携带Token访问API
   ↓
4. 验证Token有效性和权限
   ↓
5. Token过期使用refresh_token刷新
```

### 权限控制

```
多租户隔离
   ↓
用户级权限 (admin/annotator/reviewer)
   ↓
资源级权限 (项目/资产/标注)
   ↓
操作级权限 (read/write/delete)
```

### 数据安全

- 密码使用bcrypt加密存储
- 敏感数据脱敏
- SQL注入防护 (ORM参数化查询)
- XSS防护 (响应头配置)
- CSRF防护 (Token验证)
- 速率限制 (待实现)
