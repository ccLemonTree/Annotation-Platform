## 🚀 后端快速启动

### 1. 克隆项目（假设）
```bash
git clone <repository-url>
cd 数据管理平台/backend/backend
```

### 2. 创建虚拟环境
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux/Mac
python3 -m venv venv
source venv/bin/activate
```

### 3. 安装依赖
```bash
pip install -r requirements.txt
```

**核心依赖**:

### 4. 配置环境变量

创建 `.env` 文件：

```bash
# 应用配置
APP_NAME="数据管理平台"
APP_ENV="development"
DEBUG=true
API_PREFIX="/api/v1"

# 数据库配置
DATABASE_URL="postgresql+asyncpg://postgres:password@localhost:5432/annotation_platform"

# 存储配置
STORAGE_TYPE="local"  # local 或 s3
LOCAL_STORAGE_PATH="./storage"

# S3配置（如果使用S3）
# AWS_ACCESS_KEY_ID="your-key"
# AWS_SECRET_ACCESS_KEY="your-secret"
# AWS_REGION="us-east-1"
# S3_BUCKET="your-bucket"

# JWT配置
SECRET_KEY="your-secret-key-change-this-in-production"
ALGORITHM="HS256"
ACCESS_TOKEN_EXPIRE_MINUTES=30

# CORS配置
CORS_ORIGINS="http://localhost:3000,http://localhost:5173"
```

### 5. 初始化数据库

```bash
# 创建数据库
createdb annotation_platform

# 运行迁移
alembic upgrade head
```

**如果遇到编码问题**:
```bash
# 使用UTF-8编码重新创建数据库
dropdb annotation_platform
createdb annotation_platform --encoding=UTF8 --locale=en_US.UTF-8
```

### 6. 启动开发服务器

```bash
python main.py
```

或使用uvicorn:
```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

### 7. 验证安装

访问以下URL验证：

- **健康检查**: http://localhost:8000/health
- **根路径**: http://localhost:8000/
- **API文档**: http://localhost:8000/docs (Swagger UI)
- **备用文档**: http://localhost:8000/redoc (ReDoc)

## 🗃️ 数据库管理

### Alembic常用命令

```bash
# 查看当前版本
alembic current

# 查看迁移历史
alembic history --verbose

# 创建新迁移（自动检测模型变化）
alembic revision --autogenerate -m "描述信息"

# 升级到最新版本
alembic upgrade head

# 升级到指定版本
alembic upgrade <revision_id>

# 降级一个版本
alembic downgrade -1

# 降级到指定版本
alembic downgrade <revision_id>

# 查看SQL（不执行）
alembic upgrade head --sql
```

### 手动创建测试数据

```python
# create_test_data.py
import asyncio
from sqlalchemy.ext.asyncio import AsyncSession
from models import Tenant, User, UserRole, async_session_maker

async def create_test_data():
    async with async_session_maker() as session:
        # 创建租户
        tenant = Tenant(
            tenant_name="测试租户",
            contact_email="test@example.com"
        )
        session.add(tenant)
        await session.commit()
        await session.refresh(tenant)
        
        # 创建管理员用户
        admin = User(
            tenant_id=str(tenant.id),
            username="admin",
            email="admin@example.com",
            password_hash="hashed_password",  # 实际应使用bcrypt
            full_name="管理员",
            role=UserRole.ADMIN
        )
        session.add(admin)
        await session.commit()
        
        print(f"✅ 创建测试租户: {tenant.tenant_name} (ID: {tenant.id})")
        print(f"✅ 创建管理员用户: {admin.username}")

if __name__ == "__main__":
    asyncio.run(create_test_data())
```

运行：
```bash
python create_test_data.py
```

## 🐛 常见问题

### 1. 数据库连接失败

**症状**: `sqlalchemy.exc.OperationalError: could not connect to server`

**解决**:
```bash
# 检查PostgreSQL是否运行
pg_isready

# 检查连接字符串
echo $DATABASE_URL

# 测试连接
psql -U postgres -d annotation_platform -c "SELECT 1"
```

### 2. Alembic迁移失败

**症状**: `Target database is not up to date`

**解决**:
```bash
# 查看当前版本
alembic current

# 如果数据库为空，直接升级
alembic upgrade head

# 如果有冲突，可能需要手动处理
alembic history
```

### 3. 模块导入错误

**症状**: `ModuleNotFoundError: No module named 'models'`

**解决**:
```bash
# 确保在正确的目录
pwd  # 应该在 backend/backend/

# 检查PYTHONPATH
export PYTHONPATH="${PYTHONPATH}:$(pwd)"

# 或在代码中添加
import sys
sys.path.insert(0, '.')
```

### 4. 编码问题（Windows）

**症状**: `UnicodeDecodeError: 'gbk' codec can't decode`

**解决**:
```bash
# 设置环境变量
set PYTHONUTF8=1
set PYTHONIOENCODING=utf-8

# 或在代码开头添加
# -*- coding: utf-8 -*-
```

### 5. 端口被占用

**症状**: `OSError: [Errno 48] Address already in use`

**解决**:
```bash
# Windows
netstat -ano | findstr :8000
taskkill /PID <PID> /F

# Linux/Mac
lsof -ti:8000 | xargs kill -9

# 或使用其他端口
uvicorn main:app --port 8001
```

## 🔑 核心概念

### 1. 多租户隔离
- 所有数据通过 `tenant_id` 隔离
- 用户只能访问自己租户的数据
- 中间件自动过滤（待实现）

### 2. 零拷贝架构
- SmartEye下载的图片存储一次
- Asset表通过 `blob_path` 引用原始文件
- 通过 `content_hash` 去重

### 3. 导入批次追溯
- `ImportBatch` 记录数据来源
- 可追溯每个Asset的导入批次
- 支持批量操作

### 4. 版本化标注
- `Annotation` 支持多版本
- `is_latest` 标记最新版本
- 审核状态独立管理
